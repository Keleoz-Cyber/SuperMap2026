# v0.8.0 第二批统计与空间分析中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在统一案例工作台后增加一个差异化统计与空间分析中心，让微震速度、电阻率和未来瓦斯案例使用不同的地质属性分析，同时为自定义数据提供可靠的通用降级。

**Architecture:** 后端按不可变 dataset version 和可选 materialized result 计算只读分析摘要，使用 `analysis_profile` 注册表选择领域模块。前端新增独立 AnalysisCenterView，以 A+B 混合信息架构展示空间主视图、统计指标、分布图、模型对比和剖面联动；0.9.0 再复用该数据契约加入结论看板。

**Tech Stack:** Python 3.12、FastAPI、Pydantic v2、pandas/numpy/scipy、SQLAlchemy 现有 runtime；Vue 3、TypeScript、Element Plus、ECharts、Vitest、Playwright、真实 SuperMap SDK live gate。
