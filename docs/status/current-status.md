## 3. 算法与验证

- IDW：支持 2D/3D、幂次、邻域和专业邻域参数。
- 普通克里金：球状、指数和高斯变异函数；支持自动拟合或人工参数。
- DSI-like：IDW 初始场 + 邻域平滑 + 观测点硬约束的工程近似。
- 随机森林空间回归：使用坐标派生特征和确定性随机种子。
- 克里金残差随机森林：用折外克里金残差训练校正模型，避免把训练点拟合残差泄漏给验证折。

候选比较必须使用相同折分指纹和公共有效集。正式选择要求运行和候选均为 `succeeded`；关键 OOF、折分、成果和领域证据读取前重新校验大小与 SHA-256。机器学习没有优于普通克里金时，界面必须如实说明，不强行推荐。

## 4. 三维与 SuperMap

- v0.6.1 正式三维成果使用 **NetCDF classic/v3** 规则网格，并由 SuperMap3D `VoxelGridLayer3D` 渲染；局部模型使用 `display_anchor_only` 显示锚点，`auxiliary points` 只能作为辅助/证据层。
- 支持 Volume、Contour、X/Y/Z Slice；切片坐标和统计来自后端权威切片 API。
- `gmp-supermap-volume/v2` 使用完整状态和单调 `revision`，拒绝过期消息。
- 单轴切片隐藏其他轴是 SuperMap3D 12.1 本机探针验证出的行为，不是公开 API 保证。
- iServer 作为发布和服务能力接入；iServer 离线时，通用建模主链仍可运行，但发布状态必须如实降级。
- 渲染遵守 `no silent fallback`：失败不改画点云冒充体渲染。32^3/64^3 基准用于真实 SDK 性能与交互发布门。
- PR #10 已合并入 main；其 `/volume-demo` 自研 WebGL POC 已被 NetCDF 原生路径取代，属于非产品路由。

集成细节见[SuperMap 集成说明](../supermap-integration.md)。

## 7. 已知边界

1. 三个案例使用独立局部坐标，不能直接叠加成一个真实地理空间。
2. 微震绝对原点、方位角和 CRS 仍未知；当前局部几何只用于本案例建模。
3. 瓦斯样本量不足，不能把插值场描述成高置信度危险分区。
4. 不提供任意斜切。
5. 通用上传成果发布默认 `manual_required`。
6. AI 研判是可选解释层，不取代确定性指标、规则和人工判断。
7. SuperMap SDK/iServer 版本、许可证、服务和端口属于动态环境，演示前必须运行 `demo-check` 并现场复核。
