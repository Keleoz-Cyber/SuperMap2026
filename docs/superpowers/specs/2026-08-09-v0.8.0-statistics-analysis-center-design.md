# v0.8.0 第二批：差异化统计与空间分析中心

## 1. 目标

在现有 NetCDF 原生体渲染、切片、剖面和插值结果链之上，增加一个面向案例解释的统计与空间分析中心。

这个中心是答辩展示中仅次于体渲染的核心页面。它不把三个示例强行做成同一套模板，而是采用：

> 统一分析工作台 + 地质属性专属分析配置 + 自定义数据通用降级。

页面应帮助用户回答三件事：

1. 数据是否可靠、覆盖是否充分？
2. 当前地质属性呈现出什么空间特征？
3. 这些判断由哪个结果、哪个切片或哪个模型指标支持？

## 2. 范围

### 本批实现

- 统一分析工作台路由和布局壳。
- 数据质量摘要和基础统计摘要。
- 分布图、空间分布、剖面统计和插值模型对比。
- 微震速度和电阻率的专属分析配置。
- 自定义数据的通用分析降级。
- 统计项与成果页 Volume/Slice/Contour/剖面的联动入口。
- CSV、JSON 和可打印报告导出。
- 桌面端高信息密度布局和移动端可用降级。

### 本批不实现

- 不伪造瓦斯正式数据或瓦斯专业结论。
- 不实现 AI 预测、iServer/S3M 发布和真实 CRS 配准。
- 不在本批重做全系统导航、首页和所有旧页面视觉；这些属于 v0.9.0 收尾。
- 不把统计结果当作地质结论自动发布；结论必须有数据证据和适用范围。

## 3. 用户入口与流程

统一从案例工作台进入“统计与空间分析”。入口必须显示案例名、数据版本、变量名、单位和坐标类型。

标准流程：

1. 进入案例工作台。
2. 选择一个已验证数据版本或已物化成果。
3. 打开统计与空间分析中心。
4. 查看“数据质量”和“案例特征”摘要。
5. 在空间特征、模型对比、剖面统计之间切换。
6. 点击图表中的区域、区间或模型，跳转到对应成果页并保留筛选状态。
7. 导出当前分析或完整报告。

对于没有验证数据、没有物化成果或数据字段不满足专业分析要求的案例，页面应显示明确的通用降级状态和缺失原因，不显示空图或误导性结论。

## 4. 分析配置模型

后端返回稳定的 `analysis_profile`，前端根据配置渲染模块，不根据案例 ID 写条件分支。

建议的 profile：

| profile | 案例 | 专属重点 |
| --- | --- | --- |
| `microseismic_velocity` | 微震速度 | 速度分布、方向趋势、速度梯度、空间异常 |
| `resistivity` | 地下电阻率 | 对数分布、高低阻区、深度变化、异常体积、模型差异 |
| `gas_content` | 瓦斯（数据到位后） | 含量分布、阈值区、深度变化、空间聚集 |
| `generic_3d` | 用户自定义数据 | 质量、基础统计、分布、空间范围和通用剖面 |

配置只声明“可以展示什么”和所需字段，不直接写入具体统计结果。所有统计结果由后端基于数据版本和结果身份计算并带 provenance。

## 5. 案例差异化分析

### 5.1 微震速度

- Vx 的有效值分布、分位数和异常区间。
- X/Y/Z 方向的均值、中位数和趋势变化。
- 速度梯度或局部变化强度。
- 空间高值/低值区域及其体积占比。
- IDW、普通 Kriging、DSI-like 的 RMSE、MAE、R²、Bias 对比（仅展示实际存在的算法）。
- 不生成时间演化、震源能量等数据中不存在的指标。

### 5.2 地下电阻率

- 默认使用对数尺度展示分布，同时保留原始值统计。
- 高阻/低阻阈值由分位数或用户明确输入产生，并显示阈值来源。
- 各 Z 层的异常面积或体积占比。
- X/Y/Z 方向的变化率和剖面统计。
- 三种插值算法的误差、空间差异和结果身份对比。
- 单位和地质解释保持数据合同口径；单位未确认时禁止生成水、矿、瓦斯通道等语义结论。

### 5.3 瓦斯

瓦斯源数据和单位合同确定后再启用 `gas_content` profile。首版只承诺基于真实字段提供含量分布、阈值区、深度变化和空间聚集，不提前设计无法由数据支持的安全结论。

### 5.4 自定义数据

如果数据不满足某个专属 profile 的字段要求，自动降级到 `generic_3d`：

- 有限性、缺失和重复检查。
- 行数、坐标范围和基本统计。
- 分布图和 XYZ 剖面。
- 已物化成果的模型指标。
- 可用的切片和导出能力。

降级状态必须写出“缺少哪些字段/为什么未启用专业分析”，不能静默显示一个看似完整的专业面板。

## 7. 前端信息架构

### 默认桌面布局：A+B 混合

- 顶栏：案例身份、数据版本、变量/单位、数据质量状态、导出。
- 左侧窄栏：分析模块导航和当前选中状态。
- 中央主区：空间视图或主图表；默认优先显示空间范围/异常分布。
- 右侧信息栏：关键指标、算法对比、证据入口。
- 底部可折叠区：剖面统计、表格明细、数据来源和计算说明。

该布局追求信息密度，但不把所有图表同时铺满。主视图只保留一个视觉焦点，其余模块服务于解释和复核。

### 交互原则

- 点击统计区间、空间区域或模型行，能定位到对应成果视图。
- 所有图表提供单位、数据范围和样本数。
- 统计模块显示计算时间、数据版本和来源哈希。
- 专业模块不可用时，使用解释性空状态，不显示空白图表。
- 不使用大面积装饰性渐变、漂浮圆球或卡片套卡片。
- 移动端采用纵向信息流，保证页面不横向溢出；复杂表格在内部滚动。

### 0.9.0 预留

分析中心保留“展示模式”入口，后续加入 C 类结论看板：发现、证据、三维定位和可打印答辩页面。0.8.0 不提前实现完整叙事模式。

## 8. 错误与降级

- 案例被回收：沿用 `410 CASE_TRASHED`。
- 数据版本不存在或未验证：显示数据准备状态和继续操作入口。
- 专业字段缺失：显示 generic profile 及缺失字段。
- 统计计算失败：保留质量和原始元数据，模块级显示错误与重试，不影响成果页。
- 结果未物化：模型指标可显示，空间体积分析标记为不可用。

## 9. 验收标准

### 数据与接口

- 微震、电阻率各自返回正确的 `analysis_profile` 和专属模块。
- 自定义数据能稳定降级到 `generic_3d`。
- 所有统计值可追溯到数据版本和源哈希。
- 无有限公共集时 fail-closed，并有类型化状态。

### 前端与交互

- 桌面端首屏能同时看到案例身份、关键指标、主空间视图和至少一个模型对比摘要。
- 微震和电阻率页面的信息模块明显不同，但导航、单位、来源和导出方式一致。
- 统计项到成果页的联动可用，返回时保留筛选语义。
- 390x844 页面无横向溢出，图表和表格不遮挡主要操作。

### 真实视觉验收

- 使用真实微震和电阻率源数据，在真实 SDK 运行库上核验至少一个桌面和一个移动视口。
- 截图中不得是黑屏、Logo-only、近单色背景或空白图表。
- 至少核验一个空间选择、一个剖面切换和一个模型对比交互产生可见响应。

## 10. 实施分期

1. 先锁定 profile、统计 DTO 和通用降级契约。
2. 实现分析中心壳和通用质量/统计模块。
3. 实现微震速度专属模块。
4. 实现电阻率专属模块。
5. 加入模型对比、空间联动和导出。
6. 完成真实数据视觉验收和文档证据。
7. 瓦斯数据合同准备好后，作为独立 profile 接入。

## 11. 设计决策

- 0.8.0 第二批做统计与空间分析中心，不先等待瓦斯数据。
- A+B 是默认产品形态，C 延后到 0.9.0。
- 专业分析通过配置和字段能力启用，不通过案例 ID 硬编码。
- 任何地质解释必须有数据字段、阈值来源和可回溯证据。
