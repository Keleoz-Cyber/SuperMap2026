# 地质属性解释工作台设计

## 目标

在不改变现有插值、成果物化、三维渲染和 AI 调用边界的前提下，将成果页从“数值场查看器”升级为“事实—解释—影响—建议”闭环的地质属性解释工作台。产品版本保持 `0.9.2`。

## 产品原则

1. 三维场景是主视觉，研判卡与异常体双向联动。
2. 规则库负责专业措辞、边界和建议；AI 仅整理已有证据。
3. 电阻率、微震速度、瓦斯使用独立语义；自定义变量只显示通用统计。
4. 分位异常一律标为“探索性”，不能自动认定含水区、断层、危险区或储量。
5. 面积与体积仅称“模型/网格支持量”；坐标、网格与边界证据充分时才允许解释为实际量。

## 页面结构

- 顶部：案例身份、属性、模型状态、返回入口。
- 中央：三维场景与现有控制栏，保持最大可视面积。
- 右侧：`地质研判 / AI 辅助`；通用数据降级为 `规则研判 / AI 辅助`。
- 底部：保留综合分析、切片与异常、模型证据、数据溯源。
- 低于 1440 px 时不强行并排：提供 `场景 / 控制 / 研判 / 分析` 四个工作区按钮，默认场景，保证 1280×720 和 1366×768 在 100% 缩放下可完整操作。

## 后端合同

成果分析摘要新增 `domain_interpretation`，由版本化确定性规则生成：

- `profile`：`resistivity | microseismic_velocity | gas_content | generic_3d`；
- `rule_version`：规则库版本；
- `panel_label`、`overview`、`status`；
- `cards[]`：异常方向、标题、解释、潜在影响、建议核查、证据、限制、可信等级和空间目标；
- `global_limitations[]`：案例级边界说明。

成果分析同时保留高值连通区，并增加低值连通区。高值组件 ID 维持原值；低值组件 ID 使用独立稳定命名空间，避免三维标注冲突。两类组件均携带 `direction`。

## 规则语义

### 电阻率

- 低阻：可能与含水、裂隙发育、黏土富集或导电矿物有关；建议结合钻孔、水文及其他物探资料。
- 高阻：可能与较致密、较干燥或高阻岩性有关；建议结合岩性与构造资料。
- 禁止直接输出含水、成矿或安全结论。

### 微震速度

- 低速：可能与松散、破碎、裂隙、孔隙或流体差异有关。
- 高速：可能与较致密、较完整介质或应力/岩性差异有关。
- 禁止解释为事件活跃度、震源能量或直接认定断层。

### 煤层瓦斯

- 高含量：作为重点复核与治理布置参考，建议结合矿区阈值、钻孔、压力、抽采与通风资料。
- 低含量：只作为相对分区，不得推导“安全区”。
- 未登记权威阈值时不得生成危险等级或安全等级。

### 通用变量

不生成专业解释卡，仅说明当前变量没有匹配到受控规则库，可继续使用数值分析和 AI 对既有证据做非专业摘要。

## 交互

1. 点击研判卡“定位三维”时聚焦对应连通区。
2. 点击三维标注时反选对应研判卡并滚动到可视区域。
3. 高低异常使用不同视觉身份；当前选中项具有高亮描边，未选项弱化。
4. 卡片默认只显示标题、结论和关键指标，展开后显示解释、影响、建议、限制和规则来源。
5. AI 不可用时，地质研判完整保留。

## 视觉规范

- 深色专业科技风，减少同质化边框和卡片嵌套。
- 电阻率使用琥珀黄/深蓝，微震使用紫蓝/青色，瓦斯使用青绿/橙红。
- `事实 / 解释 / 影响 / 建议` 使用固定短标签，数值使用等宽字体。
- `规则支持 / 探索性 / 不适用` 使用文字状态，不使用虚构百分比置信度。

## 失败与降级

- 无有效格点、合同损坏：沿用现有 fail-closed 分析错误。
- 无连通区：显示确定性空态，不生成异常结论。
- 未识别变量：降级通用规则，不猜测专业含义。
- 接触网格边界：明确提示异常范围可能被模型边界截断。
- AI 未配置、超时或离线：只影响 AI 标签页。

## 验收

1. 三个官方案例分别显示正确属性术语和禁止声明边界。
2. 高低异常组件 ID 唯一，卡片与三维定位双向一致。
3. 通用数据不出现含水、断层、危险或安全等专业结论。
4. 1280×720、1366×768、1920×1080 在 100% 缩放下无横向溢出，场景和研判均可到达。
5. 后端规则合同、前端组件、Mock E2E 和真实浏览器关键链路通过；版本号仍为 `0.9.2`。
