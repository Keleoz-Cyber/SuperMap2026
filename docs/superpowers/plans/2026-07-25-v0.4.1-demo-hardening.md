# GeoModelingPlatform v0.4.1 Demo Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不进行视觉重构、不破坏 v0.4.0 通用建模与 v0.3.1 电阻率只读链路的前提下，消除浏览器导航死路，增加固定演示数据、启动前检查、Windows 单机启动脚本、真实 FastAPI 浏览器验收和答辩运行手册，形成可发布的 v0.4.1 演示可靠性版本。

**Architecture:** 保持现有 Vue 3 → FastAPI → `PlatformRuntime`/SQLite → 建模 Worker 的单机单进程架构。新增的导航只通过轻量组件和命名路由实现；演示数据由仓库内唯一权威 CSV 提供并经 SHA-256 固定；`demo-check` 以可注入探针生成稳定检查契约；Live E2E 使用独立临时运行目录和独立端口启动真实应用，不依赖 iServer、私有资料或 Mock API。内置电阻率/iServer 路线继续作为独立兜底，不改变其 fail-closed 契约。

**Tech Stack:** Python 3.12、Typer、FastAPI、SQLAlchemy/SQLite、pytest、Vue 3、Vue Router、Element Plus、Vitest、Playwright、PowerShell、GitHub Actions。
