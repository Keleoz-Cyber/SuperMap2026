# Resistivity MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable underground resistivity MVP that registers datasets, validates contracts, imports SuperMap prediction exports, recomputes baseline metrics, manages model/result state, and exports traceable reports.

**Architecture:** Python package `geomodeling` with a Typer CLI, file-backed JSON registries under ignored `artifacts/`, YAML configuration, pydantic schemas, pandas/numpy validation and metrics, and pytest regression tests against real baseline files. SuperMap is represented by a configuration/evidence registry rather than UI automation.

**Tech Stack:** Python 3.12, pandas, numpy, pydantic, Typer, Rich, PyYAML, pytest.
