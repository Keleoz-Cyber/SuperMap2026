# v0.9.0 V6 成果工作台重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将正式成果页重构为与 `geological-analysis-workbench-v6-preview.html` 同构、且真实功能和视觉完成度更高的一屏式成果工作台；同时默认关闭光照与渐变透明度、移除答辩模式，并让 XYZ 坐标轴脱离包围盒且更易读。

**Architecture:** 保留现有 FastAPI 成果分析、NetCDF 体渲染、切片、异常组件、模型评估与 AI 辅助合同；仅重构 Vue 页面组合和 SuperMap 帧的场景辅助物。`ResultWorkbenchView` 负责成果专用顶栏和摘要条，`ResultAnalysisWorkbench` 负责三段式主舞台与固定证据带，`NativeVolumePanel` 继续拥有真实渲染状态但以 `workbench` 变体隐藏调试性外壳。默认渲染参数在后端 `RenderProfile` 与前端无 profile 降级值上同时改为 false，避免来源不同导致视觉状态漂移。

**Tech Stack:** Vue 3、TypeScript、Vitest、Vue Test Utils、Playwright、FastAPI/Pydantic、pytest、SuperMap3D/iClient3D、CSS Grid。

## Task 5：拉长并外移 XYZ 轴，放大真实体场取景

**Files:**

**Step 1: 给辅助轴几何增加纯函数与诊断**

将轴计算提取成可测试函数。以包围盒各轴 span 为基准：

```js
const origin = [west - lonSpan * 0.10, south - latSpan * 0.10, zMin - zSpan * 0.08]
const xEnd = [origin[0] + lonSpan * 1.25, origin[1], origin[2]]
const yEnd = [origin[0], origin[1] + latSpan * 1.25, origin[2]]
const zEnd = [origin[0], origin[1], origin[2] + zSpan * 1.25]
```

要求：原点同时位于包围盒 west/south/bottom 外；X/Y/Z 轴可见长度为对应包围盒 span 的 1.2–1.3 倍；轴端标注不再贴在包围盒顶点。深度刻度沿独立 Z 标尺绘制，不复用包围盒边。

在诊断回执中加入：

```ts
sceneAidsGeometry: {
  originOutsideBounds: boolean
  axisLengthRatios: { x: number; y: number; z: number }
}
```

失败时不得假报 ready。

**Step 2: 调整相机距离但不改变数据几何**

将 `applyCameraPreset` 的取景常数集中为命名常量；等轴初始视角先以 `span * 1.65`、正视图以 `span * 1.55` 起步。最终值只能依据真实 GPU 截图调整，目标是体场占中央场景高度 58%–72%，不能缩放顶点或改 display transform 伪造大小。

**Step 3: 写协议和 live 断言**

live 测试必须确认：

```ts
expect(diag.sceneAidsGeometry.originOutsideBounds).toBe(true)
expect(diag.sceneAidsGeometry.axisLengthRatios.x).toBeGreaterThanOrEqual(1.2)
expect(diag.sceneAidsGeometry.axisLengthRatios.x).toBeLessThanOrEqual(1.3)
```

Y/Z 同口径；再对真实 iframe 非背景像素包围盒计算高度占比，超出 58%–72% 即失败。
