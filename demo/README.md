# 演示数据说明

`platform_demo_3d.csv` 是 GeoModelingPlatform v0.4.1 的**唯一权威演示数据文件**。

## 性质

- **人工合成演示样例**：由固定种子的解析函数生成，不来自原始论文、私有资料或真实矿区。
- 144 行（6×6 XY 网格 × 4 个 Z 层），列：`x,y,z,rho`。
- 坐标为局部线性米制坐标，**没有地理 CRS**；`rho` 是演示属性值，不声明物理单位。
- 值域约 67–240，带明显三维梯度，适合快速 IDW 与普通克里金演示、切片和三维点云展示。

## 推荐映射

| 源列 | 语义角色 |
|---|---|
| `x` | X |
| `y` | Y |
| `z` | Z |
| `rho` | value（属性名可填“电阻率（演示）”） |

坐标类型：`local_linear`；维度：`3d`。

- 文件被修改时启动前检查会阻断，不允许静默继续演示。

## 使用

- 浏览器：首页「下载演示数据」（`GET /api/demo/datasets/platform-demo-3d`），然后走完整「新建案例 → 上传 → 映射 → 质量门禁」流程——下载不自动创建案例、不跳过上传。
- 测试：需要同一数据的测试直接读取本文件，不再维护第二份同内容 CSV。
