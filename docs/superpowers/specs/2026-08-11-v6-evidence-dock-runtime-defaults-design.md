# V6 成果工作台证据窗与渲染默认值修复设计

日期：2026-08-11  
范围：`feat/v0.9.0-visual-product` 的成果工作台与首页官方成果预览。

## 目标

1. 底部“分析证据”不再被一屏外壳裁切，所有图表、表格都能滚动到末尾。
2. 默认状态下仍能看到核心证据；需要细看时，可把证据窗展开到约半屏，再一键还原。
3. 光照和渐变透明度首次进入成果时强制关闭，不再被后端渲染配置中的 `true` 覆盖；用户仍可手动打开。
4. 首页官方成果预览删除“刷新状态”和资产哈希、渲染身份等调试信息。正式身份信息只在成果页“数据溯源”中展示。

## 方案

### 证据窗

- 工作台维持一屏布局，不恢复整页纵向滚动。
- 证据内容区在纵向 flex 中使用剩余高度，并设置自身 `overflow-y: auto`；外层隐藏越界内容，杜绝内容穿出证据窗后被页面裁切。
- 默认高度使用约 `clamp(280px, 29vh, 330px)`，保证 1920×1080 与 1440×900 均可见标题和核心图形。
- 证据栏增加“展开分析/收起分析”按钮：
  - 默认态显示核心图形；
  - 展开态约占工作台可用高度的 52%，证据内容仍可内部滚动；
  - 切换只改变布局，不卸载或重建三维 iframe，不丢失相机、切片和筛选状态。
- 在窄屏或低高度窗口中回退为普通页面流，避免三栏和固定证据窗互相挤压。

### 渲染默认值

- `NativeVolumePanel` 初始状态与资产身份切换后的重置状态，都明确设为：
  - `lighting: false`
  - `gradientOpacity: false`
- 后端 `render_profile` 仍提供能力、色带、标度、值域、包围盒和透明度；但不再决定上述两个首次显示开关。
- 用户手动改变开关后，当前成果会话内保持其选择；重新载入或切换成果时回到关闭状态。

### 首页清理

- ready 资产不显示“刷新状态”。
- 首页不显示资产 ID、网格 SHA、NetCDF SHA、坐标契约和渲染身份调试块。
- 创建失败、资产失败或中断时仍保留明确错误和“重试生成”动作，不能为了视觉简化而删除恢复能力。
- 成果页“数据溯源”继续保留正式的渲染资产身份与哈希信息。

## 验收

- 单元测试先证明：即使后端 profile 返回两个开关为 `true`，首次发送给渲染器的状态仍为 `false`。
- 组件测试覆盖证据窗默认、展开、还原状态，并确认场景组件不因切换而卸载。
- 浏览器在 1920×1080 和 1440×900 下验证：
  - 页面无横向溢出；
  - 默认窗可见核心图表；
  - 展开后图表/表格能滚动到真正末尾；
  - 光照与渐变透明度复选框均未选中；
  - 首页不再出现指定调试块；
  - 控制台错误为零。

## 非目标

- 不改分析指标、后端数据口径或三维几何比例。
- 不恢复答辩模式。
- 不删除失败恢复动作，不把调试信息伪装成分析结论。
- 不合并 PR、不打标签、不创建 Release。
