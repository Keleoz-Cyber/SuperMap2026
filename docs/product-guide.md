# 产品指南

> 受众：使用平台的最终用户、评委与演示操作者。本文是产品功能操作、内置案例与 AI 配置的唯一权威说明。
>
> 更新时间：2026-08-15；适用版本：1.0.0。

## 1. 项目定位

GeoModelingPlatform 是"上传数据后完成校验、调参建模、空间验证、成果分析和三维展示"的浏览器平台，不是单一插值脚本，也不是只展示预制模型的三维网页。

目标用户包括地质/GIS 学生、需要检查专业证据的建模人员，以及需要快速判断方法、结果和可信度的评委。平台把原本分散的数据处理、算法试验、证据检查和 SuperMap 三维表达收敛到同一条可追溯流程：

```text
选择案例或上传数据
  -> 字段映射与质量门禁
  -> 选择算法并调参
  -> 空间交叉验证
  -> 候选比较与适用性判断
  -> 正式成果选择和物化
  -> 三维体、等值面和 X/Y/Z 切片
  -> 统计、规则、AI 与证据导出
```

任何阶段失败都显式给出原因；禁止用空图、点云或线框冒充正式体渲染成果。

## 4. 快速上手

### 4.1 内置案例（开箱即看）

启动平台后首页即见三个内置案例卡片（电阻率、微震波速、瓦斯含量）。点击案例进入工作台，案例已预置数据、实验与主打成果，可直接进入成果工作台查看三维体渲染。内置案例为只读：可浏览全部证据，但不能在其上做正式成果选择。

### 4.2 上传自己的数据

1. 首页点「导入数据」-> 新建案例并选择 CSV/Excel 文件（≤ 50 MiB、≤ 500,000 行）；
2. 在数据准备向导中完成字段映射（X/Y/属性值必填，Z 可选；2D/3D；投影坐标，暂不支持经纬度地理坐标）；
3. 提交映射后自动质量校验；blocker 必须修复，warning 需要整体显式确认后才放行；
4. 进入「新建实验」，选择算法与参数，启动运行；
5. 运行完成后查看候选排行榜，物化成果并进入成果工作台。

向导支持断点续传：刷新或中断后重新进入会按服务端数据版本状态（已上传/已映射/待质量确认）自动回到对应阶段。

### 4.3 演示数据

首页可下载固定演示数据 `platform_demo_3d.csv`（144 行合成三维梯度数据），走完整上传链体验全流程；数据合同见 [demo/README.md](../demo/README.md)。

## 5. 数据接入与质量门禁

- 上传为原子操作：边传边算 SHA-256，失败不留半成品；相同文件重复上传自动复用。
- 检查阶段提供前 20 行预览、列类型推断与候选字段映射（支持 Excel 多工作表切换）。
- 质量门禁分两级：
  - **blocker（阻断实验）**：数值缺失、非有限值、NoData 哨兵值（-9999）、坐标冲突、有效点不足（2D < 10 / 3D < 20）、空间范围退化；
  - **warning（需精确确认）**：重复行、极端值（MAD×6）、空间分布稀疏、数值量级可疑、无效行占比高（> 5%）。确认必须与未决警告集合完全一致，不允许漏确认。
- 无效值保留原始 token 与源行号；NoData 与真实 0 分开处理，绝不偷改。
- 未完成的数据版本可显式「放弃」，不影响该案例历史版本。

## 6. 建模实验

### 6.1 五种算法

| 算法 | 维度 | 要点 |
|---|---|---|
| IDW 反距离加权 | 2D/3D | 幂次、邻点数、搜索半径、z 缩放、专业旋转邻域 |
| 普通克里金 | 2D/3D | 球状/指数/高斯变异函数；自动拟合或人工块金/基台/变程；提供估计标准差 |
| DSI-like 离散平滑 | 仅 3D | IDW 初始场 + 离散邻域平滑 + 观测点硬约束；工程近似，不等同 GOCAD DSI |
| 随机森林空间回归 | 2D/3D | 坐标派生特征；确定性随机种子；树间分歧为离散度（实验性，需适用性门） |
| 克里金残差随机森林 | 2D/3D | 克里金基线 + 折外残差校正，防泄漏两段式（实验性，需适用性门） |

### 6.2 搜索与验证

- 搜索模式：manual（单候选）或 grid（参数网格乘积，>30 提示、>50 硬上限拒绝）。
- 空间验证：整 XY 柱空间 k 折（默认 5 折，可设种子）或空间留出（默认 20%）。
- 克里金建模依据可选「快速建模」或「采用空间结构分析建议」（复用已确认的专业诊断快照，附加旋转邻域与经验误差尺度）。
- 自定义输出网格（范围 + 分辨率）；不填则由系统按 10 万节点预算自动推导。
- ML 适用性门：按有效样本数与独立空间组判定 supported / experimental / not_recommended；实验性需勾选显式确认，not_recommended 拒绝创建。

### 6.3 运行行为

运行在后台单工作线程执行，页面 1 秒轮询；支持取消（排队中立即取消，运行中协作取消）与失败重试（产生新运行身份）。进程重启后中断的运行自动标记 `interrupted`，可重试。

## 7. 空间结构分析（专业诊断）

1. 进入数据集的「空间结构分析」页，配置 lag 数、点对上限与方向（方位角 0/45/90/135，3D 可加垂直方向）；
2. 提交后为后台任务（1 秒轮询），产出全向与方向经验半变异函数、拟合模型与各向异性候选；
3. **确认**：各向异性候选只是诊断建议；确认后形成不可变快照（备注必填），此后可在新建实验时直接引用；
4. 同指纹的诊断幂等复用，不会重复计算。

## 8. 成果工作台

### 8.1 物化与查看

候选运行成功后需显式「物化」才生成成果（幂等操作）：系统在持久化规则网格上全量预测，落盘 `grid.npz + metadata.json`，并保证三维画面、切片、统计引用同一份成果。ML 成果可切换 prediction / model_dispersion / kriging_baseline / residual_correction 四个场。

### 8.2 三维渲染操作

- 渲染模式：Volume（完整体）、Contour（等值阈值）、Slice（单轴切片）；
- 显示工具：5 条色带（native-spectrum/viridis/turbo/coolwarm/grayscale）、线性/对数标度（对数要求全正）、值域滤波、不透明度曲线、光照与梯度透明度、包围盒、XYZ 轴与深度刻度、四种相机预设（等轴/顶视/前视/侧视）；
- 正交切片：X/Y/Z 轴选择与整数层滑块，切片统计（min/max/mean/std/P10/P50/P90/NoData）由后端权威计算；
- 观测点叠加层与异常标注（点击标注可回定位分析组件）；
- 剖面热力图可导出 PNG（标记为客户端画布产物）。

### 8.3 分析与研判

- 底部证据窗四标签：综合分析 / 切片与异常 / 模型证据 / 数据溯源；
- 右侧研判区：「规则研判」为版本化确定性规则生成的高/低值异常解释（数值事实 -> 可能解释 -> 潜在影响 -> 建议核查）；「AI 辅助」为可选 DeepSeek 分析（见第 13 节）；
- 顶部摘要：R²、公共有效数、正式成果状态、证据包导出。

### 8.4 正式选择、导出与发布

- 「选为正式成果」需填写理由；只读案例（内置三案例）禁止正式选择；
- 「生成证据包」导出 ZIP：清单、元数据、指标、质量报告、选择历史、完整网格；
- 「请求发布」登记 iServer 发布意图；无实时对象级回执时状态恒为 `manual_required`，绝不虚报发布成功。

## 9. 候选比较

- **多候选比较**（候选比较中心）：从目录勾选 2-4 个候选（相同配置指纹自动禁选），返回排名、推荐、RMSE 差值与参数差异表；不兼容（数据版本/变量/单位/维度/折分不一致）时逐项给出原因并拒绝比较；
- **成对专业比较**（模型评估页）：兼容条件下给出指标差值与共同有效节点场差摘要，以比较指纹登记留档。

## 10. 统计与空间分析中心

按数据集提供只读分析面板：质量摘要、分布（直方图/分位数/log10）、空间特征（XY 热力）、逐轴剖面（X/Y/Z）、模型比较；支持 JSON/CSV 导出。模块可见性由后端数据适配结果驱动，不适用的模块显示解释性空态而非空图。

## 11. 案例管理与回收站

- 只有用户上传案例可删除；删除进入回收站，可恢复；
- 永久删除需输入案例名精确确认，走两阶段隔离提交，进行中的任务会阻止删除；
- 内置案例不可删除。

## 12. 三个内置案例

三案例使用彼此独立的局部坐标，不能叠加为同一真实地理空间。内置源字节级 SHA-256 由配置与测试锁定，修改即拒绝入库。

### 12.1 地下电阻率

- 内置源：`example_data/地下电阻率节点_标准化.csv`，字段 `X,Y,Z,RHO`，17,549 行唯一 XYZ，坐标全部有限；局部工程坐标、无 EPSG，Z 向下为负；RHO 单位 **Ω·m**，范围约 1.032113-149.984。
- 冻结普通克里金基线：exponential、neighbor=24，RMSE=6.454476；规则网格 7×23×42（6,762 单元）、间距 20 m。完整基线身份见 `config/presets/resistivity-official-baseline.json`。
- 机器学习真实证据（同一折分）：

| 候选 | 公共有效点 | RMSE | 结论 |
|---|---:|---:|---|
| 随机森林 | 17,549 | 5.546855 | 优于同折普通克里金（6.468625） |
| 克里金残差随机森林 | 17,549 | 7.326515 | 比同折克里金差 13.26%，如实显示不推荐 |

- 历史五模型导出仅作溯源：1,722 条验证记录中公共有效 1,481、NoData 241、XY 不匹配 0。

### 12.2 微震波速

- 正式源为 22 个 DAT；2,006 条源记录中 2,005 条有限；`W8.dat` 的 `1.#QNAN0` 保留溯源，不改 0、不插值填补。
- 派生规则：`depth_m = WL_half_km × 1000`，显示坐标 `z_local_m = -depth_m`；Vx 单位 km/s。
- 一次全局 3σ 使用样本标准差 `ddof=1`：剔除 80 条（深度 72、速度 8），得到 1,925 条黄金候选。
- 相同局部 XYZ 分组取算术平均，13 个冲突组使 1,925 条候选坍缩为 1,911 个唯一建模节点；黄金候选与剔除表哈希由配置冻结（候选 `4f7a0886…ae1513`、剔除表 `3752b2f6…872b1`），不一致即停止导入。
- 平台入库源为派生产物 `example_data/微震局部三维点_3Sigma_去重均值_1911.csv`（列：SAMPLE_IDS、POINT_ID、LINE_ID、X_LOCAL_M、Y_LOCAL_M、DEPTH_M、Z_LOCAL_M、VX_KM_S、N_MERGED）。
- 绝对原点、方位角和 CRS 未知，局部坐标仅限本案例；W28 只作来源冲突登记。仅 22 个独立 XY 组，随机森林必须标为实验性（真实结果：RMSE=0.250364、MAE=0.202911、R²=0.864338，不据此宣称稳定泛化）。

### 12.3 瓦斯含量

- 内置源：`example_data/瓦斯含量_合格样品.csv`，字段 `X,Y,Z,CH4_content`，58 条合格样品、28 个 XY 位置、58 个唯一 XYZ；局部线性米制坐标、无 EPSG；属性单位 `ml/g`。
- 冻结基线为普通克里金 spherical、neighbor=24：RMSE=8.298439、MAE=6.552100、R²=-0.109659、Bias=-0.068618。
- 样本稀疏且 R² 为负：成果只作为稀疏采样下的解释性估计；机器学习适用性门拒绝该案例。
- 历史 iDesktopX 中 IDW 体元加载曾触发原生崩溃；不能据此反推插值数值错误，也不约束当前 NetCDF 浏览器链。

## 13. AI（DeepSeek）配置

AI 研判是可选功能：未配置 Key、网络失败或响应无效都不影响地质研判、三维定位和建模主链。

### 13.1 产品内配置（推荐）

1. 启动平台，右上角点「AI 设置」；
2. 输入自己的 DeepSeek API Key（模型默认 `deepseek-v4-flash`）；
3. 点「测试连接」确认鉴权与网络可用；
4. 点「保存配置」，无需重启即可在成果工作台生成 AI 辅助研判。

Key 保存于当前 Windows 用户的凭据管理器（Generic Credential），页面只显示「已配置」，不回显完整 Key。平台只允许 DeepSeek 官方 HTTPS 服务地址；清除密钥在同一弹窗完成。环境变量方式配置时优先级更高，页面配置变为只读。

### 13.2 管理员环境变量临时启动（关闭窗口后失效）

免安装包解压目录打开 CMD：

```cmd
set "DEEPSEEK_API_KEY=在这里填写自己的APIKey"
GeoModelingPlatform.exe start
```

其余变量用源码默认值即可；如需覆盖：

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 无（必填才启用） | DeepSeek API 凭据 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | API 根地址 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 请求模型 ID |
| `DEEPSEEK_TIMEOUT_SEC` | `90` | 请求超时秒数 |
| `DEEPSEEK_MAX_TOKENS` | `4096` | 最大输出 token |

若页面显示 `DEEPSEEK_NOT_CONFIGURED`，通常是变量没传给当前进程：先停止平台，再从已设置变量的同一个 CMD 窗口启动。账户返回"模型不存在/不可用"时，应把 `DEEPSEEK_MODEL` 改为该账户实际支持的模型 ID。

### 13.3 安全要求

- 不把真实 Key 写进文档、源码、`.env.example`、启动脚本或截图；
- 不把团队 Key 打进免安装包；每台评测机用操作者自己的 Key；
- 不把带 Key 的窗口录进演示视频，不随 ZIP 分发 Key；
- Key 泄露立即到服务商后台撤销并重新生成；
- 没有 Key 时直接使用确定性规则分析，主链不中断。

## 14. 如何看指标

| 指标 | 含义 | 趋势 |
|---|---|---|
| RMSE | 均方根误差，对大误差敏感 | 越低越好 |
| MAE | 平均绝对误差 | 越低越好 |
| R² | 对目标变化的解释程度，可能为负 | 越高越好 |
| Bias | 平均有符号误差，反映整体高估/低估 | 越接近 0 越好 |
| Coverage | 验证点成功预测比例 | 越高越好 |
| Valid / NoData | 有效与缺失预测数 | 解释指标样本口径 |

候选排名基于所有候选共同有效的验证点（公共有效集）复算，避免有人靠标 NoData 买排名；跨实验比较先检查数据版本、折分与验证目标兼容性。

## 15. 使用边界提示

- DSI-like 是离散平滑工程近似，不等同 GOCAD DSI。
- 高低异常来自成果网格 p25/p75 分位阈值，只是探索性线索：低阻不能直接认定含水，速度异常不等于微震事件或断层，高瓦斯含量分位不等于法定危险等级。
- 随机森林离散度不是概率置信区间；克里金标准差与经验误差尺度也不是。
- 异常连通区不是危险区；网格支持体积不是储量。
- 仅支持 X/Y/Z 正交切片，不提供任意斜切。
- 三案例独立局部坐标，无共同控制点不做跨案例融合。
