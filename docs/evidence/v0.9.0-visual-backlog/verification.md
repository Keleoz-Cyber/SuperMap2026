# v0.9.0 视觉问题清单验证记录

日期：2026-08-12

分支：`feat/v0.9.0-visual-product`

服务：`http://127.0.0.1:8000/`

## 本轮已验证

- 成果工作台在 1920×1080、1440×900、1366×768 下均满足 `scrollWidth === innerWidth`、`scrollHeight === innerHeight`，没有页面级横向或纵向滚动。
- 底部分析窗支持“展开分析/收起分析”，切换时三维场景 DOM 实例不重建；展开态仍无页面级溢出。
- 双轴图只由左轴绘制水平网格线；右轴不再产生错位横线。图表启用 `containLabel`，组件支持量使用“万”级格式，深度和提示值不再输出长浮点。
- 三维异常区域列表的八项组件与标注使用同一完整数据源。真实浏览器依次点击组件 1、3、2、5、4、6、7、9（界面 A–H）均成功，未出现 `ANNOTATION_UNKNOWN`，`console error` 与 `pageerror` 为 0。
- 案例工作台四阶段会改变实际内容与 `?stage=` 查询参数；浏览器后退可恢复上一阶段。
- 首页 ready 成果不再显示刷新按钮、资产 ID、SHA 或渲染身份；失败诊断仍保留。
- 成果页首次进入时“光照”“渐变透明度”均未勾选。
- AI 快速解读显示独立说明与独立空态，界面正文未直接出现 `depth_profile`、`spatial_components`、`result_grid` 等内部证据 ID。
- 底部四类证据不再共用同一套自动列宽：综合分析为 4/8，切片与异常为空态时为 3/9，模型证据为 6/6，数据溯源为四个等宽摘要卡片；输入样本的分布、发现和轴向趋势收进默认折叠的详细分析。
- 四个页签使用独立 DOM 身份，切换后内部 `scrollTop` 均回到 0，不继承上一页签的滚动位置。
