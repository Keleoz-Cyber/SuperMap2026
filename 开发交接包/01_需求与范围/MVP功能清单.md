# 电阻率三维属性模拟 MVP 功能清单

> 文档版本：0.1
> 日期：2026-07-18
> 适用对象：产品负责人、Kimi 3 开发代理、测试人员
> MVP 数据范围：地下电阻率

## 1. 产品目标

建立一条可复现、可追溯的电阻率三维属性模拟工作链：登记标准化数据，校验数据契约，配置模型任务，关联 SuperMap 插值结果，比较模型精度，查看三维成果并输出审计记录。

第一版系统不是新的插值内核，也不承担完整三类数据融合。它优先解决数据、参数、结果和质量证据散落在不同文件及 SuperMap 工作空间中的问题。

## 2. 目标用户

- **研究人员**：登记数据、配置模型、查看精度和三维异常。
- **开发人员**：通过稳定数据契约接入算法和 SuperMap 成果。
- **答辩与审阅人员**：追溯每个成果使用的输入、参数、验证指标和限制。

## 3. 标准用户流程

1. 选择或登记标准化电阻率 CSV；
2. 系统执行字段、数量、类型、范围和空值检查；
3. 创建模型任务并选择方法、分辨率、邻点数和高程切片参数；
4. 登记 SuperMap 输出数据源、数据集名称和运行状态；
5. 导入统一验证点预测结果并比较质量指标；
6. 打开完整体元、水平/垂直切片和阈值异常视图；
7. 导出模型元数据、指标表、问题清单和成果文件索引。

## 4. 功能需求

### 4.1 数据管理

| 编号 | 功能 | 验收条件 |
|---|---|---|
| DATA-01 | 登记标准化数据集 | 保存文件路径、SHA-256、数据集类型、版本、生成时间和来源说明；再次登记相同哈希时给出重复提示 |
| DATA-02 | 校验电阻率字段 | 只接受包含 `X,Y,Z,RHO` 的输入；缺少字段时阻断并列出缺失字段 |
| DATA-03 | 校验字段类型 | 四个字段必须可解析为有限数值；不能把空串、`NaN`、无穷值或文本静默转换为 0 |
| DATA-04 | 校验数据规模 | 标准化源文件预期 17,549 条；训练集预期 15,827 条；验证集预期 1,722 条；不一致时标记异常但保留原文件 |
| DATA-05 | 计算基础统计 | 输出 XYZ 和 RHO 的最小值、最大值、唯一值数量、空值数和重复 XYZ 数 |
| DATA-06 | 管理数据分层 | 在界面和导出清单中区分原始观测、标准化数据、训练/验证数据、模型成果和可视化派生物 |

### 4.2 模型任务

| 编号 | 功能 | 验收条件 |
|---|---|---|
| MODEL-01 | 创建模型任务 | 每个任务拥有唯一 `model_id`，并保存输入数据版本和配置快照 |
| MODEL-02 | 配置插值方法 | MVP 支持登记 `KRIGING_ORDINARY` 与 `IDW`；不允许把两者保存为 `DSI` |
| MODEL-03 | 配置关键参数 | 至少记录水平分辨率、邻点数、搜索方式、最小高程、切分次数和切片间距 |
| MODEL-04 | 登记 SuperMap 成果 | 保存 UDBX 路径、数据源别名、数据集名称、数据集类型、行列波段数和运行状态 |
| MODEL-05 | 管理任务状态 | 状态固定为 `created/running/succeeded/failed/invalidated`；失败或空结果不得标记为成功 |
| MODEL-06 | 设置默认模型 | 默认模型为 `Kriging 20m/40点`，对照模型为 `IDW 20m/25点`；用户可以切换但必须显示选型依据 |

### 4.3 质量评估

| 编号 | 功能 | 验收条件 |
|---|---|---|
| QA-01 | 对齐验证结果 | 使用验证集 1,722 条记录；按行或稳定键关联后，必须检查 XY 错位数为 0 |
| QA-02 | 识别 NoData | 预测值 `-9999` 视为 NoData 并排除误差计算；显示有效点、无值点和覆盖率 |
| QA-03 | 计算统一指标 | 在公共有效点上计算 MAE、RMSE、R²、中位绝对误差、相对误差、log10 RMSE、偏差和 P90 绝对误差 |
| QA-04 | 公平比较模型 | 所有候选模型必须使用相同训练集、验证集、NoData 处理和采样方法；否则阻断横向排名 |
| QA-05 | 展示空间差异 | 至少按空间柱和深度分段显示有效数、覆盖率、MAE、RMSE 和偏差 |
| QA-06 | 输出选型结论 | 能同时陈述 `Kriging 20m/40点` MAE 最低和 `IDW 20m/25点` RMSE 最低，不生成“全面最优”结论 |

### 4.4 三维成果

| 编号 | 功能 | 验收条件 |
|---|---|---|
| VIEW-01 | 完整体元入口 | 能定位或打开 `RHO_KRIG_FINAL_20M_40`，显示模型范围、尺寸和数值范围 |
| VIEW-02 | 水平切片 | 支持按归一化 Z 显示范围或实际高程选择典型薄层，并记录切片参数 |
| VIEW-03 | 垂直切片 | 预留 X/Y 垂直剖面配置；只有实际验证显示正常后才能标记为已支持 |
| VIEW-04 | 阈值异常区 | 支持设置最小/最大可见值；以 `RHO >= 77` 作为当前演示配置，而非固定地质判据 |
| VIEW-05 | 等值面状态 | 当前显示为“未通过验证”；不得打开空数据集冒充成果 |
| VIEW-06 | 图例与单位 | 所有图例明确为电阻率 `RHO`；属性单位未从原资料获得明确证据时显示“单位待来源确认”，不得猜测 |

### 4.5 日志、错误和成果导出

| 编号 | 功能 | 验收条件 |
|---|---|---|
| AUDIT-01 | 保存操作记录 | 记录任务、操作者、时间、输入、参数、SuperMap 版本、状态和错误原文 |
| AUDIT-02 | 保存数据质量问题 | 问题包含严重级别、影响范围、证据、当前处理和是否阻断正式成果 |
| AUDIT-03 | 导出模型元数据 | 输出机器可读 JSON 和人可读 Markdown，字段符合数据契约 |
| AUDIT-04 | 导出成果清单 | 区分正式成果、验证成果、预览成果、失败/空成果；每项包含路径或 SuperMap 数据集名称 |
| AUDIT-05 | 防止错误伪成功 | 工具返回失败、对象为空、结果记录数为 0 或输出不可打开时，任务必须为 `failed` |

## 5. 非功能要求

| 编号 | 要求 | 验收条件 |
|---|---|---|
| NFR-01 | 可复现 | 同一输入哈希和参数生成相同任务配置；随机过程必须保存种子 |
| NFR-02 | 可追溯 | 任一模型可反查输入文件、参数、软件版本、验证文件和问题清单 |
| NFR-03 | 配置化 | 数据路径、SuperMap 数据集名称、阈值和模型参数不硬编码在业务逻辑中 |
| NFR-04 | 原始数据保护 | 系统只读访问 `参考资料`；派生输出写入独立目录 |
| NFR-05 | 失败透明 | 不吞掉 SuperMap 或外部算法错误；界面显示可复制的错误原文 |
| NFR-06 | 可扩展 | 微震、瓦斯和 DSI-like 通过数据集类型与模型方法枚举接入，不修改电阻率字段语义 |

## 6. MVP 暂缓项

- 微震测线完整坐标重建与三维 DSI-like 求解；
- 煤层瓦斯可信三维点层及跨数据融合；
- GOCAD SGrid、Voxet、VTU 工程转换；
- 自动成矿概率、储量和综合评价；
- 断层、地层和非结构网格编辑；
- SuperMap iServer 发布、多人账户和权限体系；
- 将原生等值面提取标记为稳定功能。

## 7. MVP 完成判定

只有同时满足下列条件才能宣布 MVP 完成：

1. 标准化电阻率 CSV 通过数据契约校验；
2. 能登记并重现主选与对照模型配置；
3. 五种已有验证结果可被正确读取，公共 NoData 数为 241；
4. 统一指标与现有总体指标表在规定浮点容差内一致；
5. 能定位完整体元并保存水平切片和阈值异常配置；
6. 等值面失败以已知问题显示，空数据集不进入正式成果；
7. 导出的模型元数据和成果清单能够反向追溯输入与参数。
