# v0.7.0 Batch 1 Unified Case Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a no-upload microseismic CSV preset with a verified official ordinary-kriging NetCDF result, and make resistivity, that preset, and user uploads enter the same case workspace.

**Architecture:** Add a `builtin_preset` identity to the existing case-card adapter and persist the microseismic preset through the normal `Case -> DatasetVersion -> Experiment -> Run -> CandidateResult -> FormalSelection` chain. Build a capability-driven `CaseWorkspaceView`; keep the existing result workbench and native SuperMap iframe unchanged. Product-visible DAT import paths are removed only after the CSV preset path is covered by tests.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy/SQLite, Pandas/NumPy/SciPy, Vue 3, TypeScript, Element Plus, Vitest, pytest, Playwright, SuperMap3D NetCDF iframe.

```python
PRESET_CASE_ID = "builtin-microseismic-vx-1911"
PRESET_VERSION = "microseismic-vx-1911/v1"
REQUIRED_COLUMNS = ("X_LOCAL_M", "Y_LOCAL_M", "Z_LOCAL_M", "VX_KM_S")

@dataclass(frozen=True)
class PresetSource:
    frame: pd.DataFrame
    sha256: str
    row_count: int
    columns: tuple[str, ...]
    value_unit: str = "km/s"
    coordinate_kind: str = "local_linear"

def load_microseismic_preset(path: Path) -> PresetSource:
    frame = pd.read_csv(path, encoding="utf-8-sig")
    if tuple(frame.columns) != REQUIRED_COLUMNS or len(frame) != 1911:
        raise PlatformError("PRESET_SOURCE_INVALID", "微震预置 CSV 合同不匹配", http_status=409)
    numeric = frame.loc[:, REQUIRED_COLUMNS].apply(pd.to_numeric, errors="coerce")
    if not np.isfinite(numeric.to_numpy(dtype="float64")).all() or numeric.iloc[:, :3].duplicated().any():
        raise PlatformError("PRESET_SOURCE_INVALID", "微震预置 CSV 含非有限值或重复 XYZ", http_status=409)
    return PresetSource(frame=numeric, sha256=sha256_file(path), row_count=len(numeric), columns=REQUIRED_COLUMNS)
```

Add `PRESET_SOURCE_INVALID`, `PRESET_BASELINE_INVALID`, `PRESET_NOT_INITIALIZED` with stable Chinese messages to the platform errors module.
