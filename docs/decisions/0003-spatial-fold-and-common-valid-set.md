# ADR-0003 整 XY 柱空间折分与公共有效集

- 状态：已接受
- 日期：2026-07-25（v0.4.0 起，v0.9.0 折分规范化加固），2026-08-15 补记

## 背景

三维地质数据常在相同 XY 位置沿 Z 密集采样：逐行随机拆分会让同一柱的相邻深度点同时进入训练集与验证集，模型相当于提前看到验证位置附近的信息（空间泄漏）。同时不同算法因邻域、NoData 或数值问题产生的有效预测点不同，各自用各自的有效点算指标则不可比。

## 决策

- 折分单位是整 XY 柱（3D 按量化容差内相同 (X,Y) 分柱；2D 按均匀网格单元分组），同一柱的所有样本只进训练侧或验证侧。
- 折分计划先行：逐行分配表在任何候选行持久化之前构建并落盘，行级或组级重叠即 `FOLD_LEAKAGE_DETECTED`，整个运行 fail-closed。
- 折分指纹 = canonical JSON（数据 SHA-256 + 验证规格 + 逐行分配）的 SHA-256；候选指纹并入算法/参数/网格/专业上下文。跨实验比较先验指纹与验证目标兼容性。
- 公共有效集：一次运行内所有成功候选非 NoData 预测点交集，全部公开指标只在交集上复算；每候选自身覆盖率与 NoData 计数单独披露。
- 折外（OOF）残差规范化落盘并纳入度量哈希引用。

## 后果

- 正面：候选比较公平且全程可审计；泄漏在结构上不可能静默发生；折证据可复核到行。
- 代价：独立空间组不足的小数据集会被拒绝折分（如瓦斯 28 个 XY 柱下 ML 被拒）--这是设计意图而非缺陷；折分计算与证据落盘增加运行成本。
- 自动变异函数只在训练折内拟合，最终场全量重拟合并标 `final_full_data_fit`，两类参数来源不混淆。
