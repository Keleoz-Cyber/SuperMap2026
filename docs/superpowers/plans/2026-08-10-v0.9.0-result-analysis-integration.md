# v0.9.0 Result Analysis and 3D Anomaly Linkage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Replace prototype-only numbers with deterministic analysis of the materialized result grid, link real anomaly components and slices to the native SuperMap3D workspace, and add an optional DeepSeek evidence-grounded review layer that never replaces deterministic analysis.

**Architecture:** Add a pure result-analysis service over existing materialized GridResult artifacts, expose a read-only result summary API, and extend authoritative slice statistics with shared grid thresholds. Reuse the existing anomaly kernel, then extend iframe protocol v2 with typed annotations and camera commands so the result page can drive and receive real spatial selections without implicit database writes.

**Tech Stack:** Python 3.12, NumPy, SciPy, Pydantic, FastAPI, Vue 3, TypeScript, Element Plus, ECharts 5, SuperMap3D 12.1, pytest, Vitest, Playwright.

2. **Frontend agent** starts from that contract checkpoint and owns Tasks 6–9 plus the frontend half of Task 10. It consumes the frozen fixture and must not invent fields or business values.
3. **Integration owner** combines backend first, frontend second, then owns Task 11, contract-parity fixes, real-data browser verification, CI and documentation.

Ownership boundaries:

- backend: `src/geomodeling/**`, backend `tests/**`, migrations and contract fixtures;
- frontend: `web/src/**`, `web/public/supermap-volume-frame/**`, Vitest and browser specs;
- integration owner: cross-stack parity checks, final docs/evidence/CI and narrowly scoped bridge fixes.

Connectivity outranks rigid ownership. If a cross-stack contract is missing, the frontend agent records the exact required field and waits for a backend contract amendment instead of adding a fake fallback. The integration owner may fix small bridge defects but does not silently redesign either side.
