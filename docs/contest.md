# 比赛交付

> 受众：团队成员与答辩操作者。本文是答辩演示路线、比赛提交结构、特色口径与边界话术的唯一权威说明。案例指标数字见 [product-guide.md](product-guide.md)；版本演进见 [CHANGELOG.md](../CHANGELOG.md)；技术细节见 [architecture.md](architecture.md)。
>
> 更新时间：2026-08-15；适用版本：1.0.0。

## 1. 答辩演示路线

主路线使用电阻率案例，建议 6-8 分钟：

1. 首页说明问题、平台闭环和三案例角色；
2. 查看电阻率数据质量与来源；
3. 展示 IDW、普通克里金或机器学习参数；
4. 展示空间交叉验证、公共有效集和候选差异；
5. 选择正式成果，在同一三维场切换 Volume/Contour/Slice；
6. 查看切片统计、异常和模型证据；
7. 展示来源哈希、数据血统和导出；
8. 用微震说明领域派生，用瓦斯说明适用性门会拒绝不可靠模型。

## 2. 演示日时间线

- **前一天**：完成全量质量门与备用截图（每关键页面至少一张，与当日版本同源）；
- **开机后**：执行 `demo-check`，确认无阻断、端口与服务身份正确；
- **上台前**：关闭系统睡眠与自动更新，确认浏览器、端口、iServer 状态与离线兜底。

兜底路线：路线 A 为通用上传建模（不依赖预置成果）；路线 B 为内置电阻率成果直达。iServer 离线时继续路线 A，不虚报在线发布。

## 3. 比赛提交

依据 [SuperMap 杯开发组要求](http://www.giscontest.com/cn/view-1000-382.aspx)，最终单层 ZIP 根目录至少包含：

1. `工程源代码/`
2. `数据/`
3. `运行文件/`
4. `作品文档/`
5. `代表性截图/`
6. 演示视频与 PPT

- 仓库保留源码、测试、CI、配置模板、脚本与必要技术证据；运行文件使用 Windows 免安装包，不复制整个开发仓库；
- 官方模板要求的 DOCX、数据说明 Excel、源代码目录说明、至少 3 张截图、1080p 演示视频和 PPT 需单独制作；仓库 Markdown 是内容源，不能替代正式模板；
- 禁止提交：`.git`、`node_modules`、缓存、临时 SQLite、日志、`.env`、API Key、iServer 管理凭据、许可证或未授权的私有论文原件。

## 4. 项目特色口径（12 条）

以下每条都有当前实现或冻结证据支撑，可作为答辩特色表述；措辞仍须遵守第 5 节边界。

1. **从"插值工具"到"建模证据平台"**：数据接入、质量、算法、调参、验证、三维、分析、导出与发布状态连成一体，用户不仅得到图，还得到结果为什么可信、哪里不可信、如何复现。
2. **整 XY 柱空间折分**：针对三维样本沿深度成柱的特点按柱折分，杜绝同柱泄漏；排名统一用公共有效集，杜绝"各算各的有效点"。
3. **算法适用性门**：不把"能运行"当"适用"；按有效样本数、独立空间组、折分可行性拒绝或降级不可靠候选（瓦斯拒绝 ML、微震标实验性是真实体现）。
4. **多算法同一生命周期**：IDW、克里金、DSI-like、随机森林、克里金残差 RF 共享数据版本、任务状态、折分、指标与证据合同，传统插值与机器学习同口径比较。
5. **防机器学习验证泄漏**：克里金残差 RF 用内部折外残差训练校正；复杂模型未更优时如实显示（残差 RF 变差 13.26% 不推荐是真实证据）。
6. **专业参数证据化**：变异函数、方向性、各向异性、旋转邻域、不确定性形成可查看、可确认、可追溯的专业证据；自动建议与人工确认分离。
7. **SuperMap 三维与后端权威成果一致**：RenderAsset、切片、统计、异常与导出共享成果 ID、网格、值域与哈希；iframe 版本化协议同步状态，杜绝"展示模型"与"分析模型"不一致。
8. **no silent fallback**：渲染、外部服务或证据校验失败显式说明，不用空图、点云或线框伪装体渲染--本身就是面向科研可信度的产品设计。
9. **三案例体现三类专业问题**：电阻率（数据充分的多算法与 ML 对照）、微震（领域派生清洗与黄金证据）、瓦斯（稀疏样本适用性拒绝与谨慎解释）。
10. **可选 AI 而非 AI 接管**：确定性规则先完成地质研判，DeepSeek 只对结构化证据做补充解释；不参与插值、阈值、规则或正式选择；无 Key 主链完整可用。
11. **结果落到核查线索**：异常的空间位置、数值范围、支持节点、触界情况与专业多解性同卡呈现，并给出可执行的钻孔/水文/岩性/测线/通风/抽采核查建议；提供的是可追溯复核入口，不是越界结论。
12. **开箱即用与可审计兼顾**：Windows 免安装包降低评测门槛；源码仓库保留测试、CI、数据合同与证据；发行文件有 SHA-256 完整性清单，运行数据与模板分离。

## 5. 已知边界与话术（答辩红线）

以下边界是产品与证据的诚实口径，答辩与文档表述不得越界：

1. 三个案例使用独立局部坐标，没有共同控制点时不做跨案例空间融合；
2. 微震绝对 CRS、原点和方位角未知；
3. 瓦斯样本稀疏，不能表述为高置信度危险分区或灾害预警；
4. 当前没有时间维度，不进行未来时间预测；
5. 不实现普适克里金、协同克里金、指示克里金和任意斜切（仅 X/Y/Z 正交切片）；
6. DSI-like 不等同商业 GOCAD DSI；
7. 各向异性候选只是诊断建议，需要人工确认，不能直接当作真实地质方向；
8. 克里金标准差、经验误差尺度和随机森林模型离散度都不是风险概率或置信区间；
9. 异常连通区域不是已验证危险区，网格支持体积不是储量；
10. 高低异常来自成果网格 p25/p75 分位，只作探索性解释：低阻不直接认定含水，速度异常不等于微震事件或断层，高瓦斯分位不等于法定危险等级；
11. iServer 通用成果发布默认 `manual_required`；没有真实对象级回执不能宣称发布成功；
12. 历史 S3M 采样点表达不是原生连续体渲染（当前正式链是 NetCDF + `VoxelGridLayer3D`，表述为"基于 SuperMap3D 的三维体元/体场表达"，不宣称所有设备已验证原生 GPU 连续体渲染）；
13. DeepSeek 只做辅助解释，不能替代专业判断；
14. 主流屏幕适配自 v0.9.2 起覆盖 1920×1080 至 1280×720 七档（Mock E2E 覆盖）；现场机器的浏览器、显卡、驱动与 SuperMap SDK 表现仍需发布前实机验收；
15. 单轴切片隐藏其他轴的行为是 SuperMap3D 12.1 本机探针事实而非公开 API 保证，SDK 升级后必须重测。
