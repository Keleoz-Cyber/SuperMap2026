# GeoModelingPlatform v0.5 Microseismic Second-Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible browser-and-CLI microseismic pipeline from 22 raw DAT files through local XYZ derivation, exact 3σ filtering, duplicate-coordinate aggregation, 3D tuning, spatial validation, slices, and evidence export.

**Architecture:** Add one microseismic domain adapter before the existing v0.4 generic modeling pipeline. Browser and CLI call the same derivation/import services; accepted source evidence remains immutable, while exactly collocated Vx records are transparently averaged into 1,911 unique modeling nodes. Existing SQLite jobs, IDW/Kriging runner, common-valid leaderboard, result workbench, and export system remain the downstream source of truth.

**Tech Stack:** Python 3.12, Pydantic v2, pandas/numpy/scipy, FastAPI, SQLAlchemy/SQLite, Typer, Vue 3, TypeScript, Element Plus, Cesium/iClient3D compatibility layer, Vitest, Playwright, pytest, GitHub Actions.

```python
def derive_local_samples(
    config: MicroseismicConfig,
    audit: MicroseismicAuditResult,
) -> tuple[list[DerivedVelocitySample], list[InvalidDerivedSample]]:
    coordinates = config.coordinate_lookup()
    finite, invalid = [], []
    for sample in audit.samples:
        if not sample.is_numeric_valid:
            invalid.append(InvalidDerivedSample.from_source(sample))
            continue
        x, y = coordinates[sample.point_id]
        depth = float(sample.wl_half_km_value) * config.derivation.depth_multiplier
        finite.append(DerivedVelocitySample.from_source(
            sample, x=x, y=y, depth=depth,
            z=depth * config.derivation.z_multiplier,
            rule_version=config.derivation.rule_version,
        ))
    return finite, invalid
```

`from_source` must copy source filename, source line and raw token; it must
raise a contract error if a supposedly finite source value is missing.

```python
def filter_three_sigma(
    rows: Sequence[DerivedVelocitySample],
    *,
    threshold: float,
    ddof: int,
) -> ThreeSigmaResult:
    depth = np.asarray([row.depth_m for row in rows], dtype="float64")
    vx = np.asarray([row.vx_km_s for row in rows], dtype="float64")
    depth_mean, vx_mean = float(depth.mean()), float(vx.mean())
    depth_std, vx_std = float(depth.std(ddof=ddof)), float(vx.std(ddof=ddof))
    depth_z = (depth - depth_mean) / depth_std
    vx_z = (vx - vx_mean) / vx_std
    # Build accepted/rejected once from these arrays; never recompute.
```

Reject when either absolute score is strictly greater than the threshold.
Store both scores on rejected rows.

```python
def scale_distance_coordinates(

    *,
```
