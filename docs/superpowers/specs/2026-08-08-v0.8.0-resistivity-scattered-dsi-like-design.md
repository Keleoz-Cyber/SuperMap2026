# v0.8.0 电阻率散点迁移与 DSI-like 设计

## 1. 目标与边界

本批将电阻率案例从只读 `builtin_legacy` 入口迁移为统一的 `builtin_preset` 散点数据案例，并新增可用于所有已验证三维散点数据的 `DSI-like` 工程近似插值算法。

本批包含：

- 电阻率标准化散点源登记、质量校验、训练/验证空间柱合同和官方基线重建；
- IDW、普通 Kriging、DSI-like 在同一实验、候选、NetCDF 和渲染链中运行；
- 电阻率与微震使用同一案例工作台和成果页面；
- 旧 legacy/S3M 入口从用户产品中停用；
- 新链路通过便携测试、Mock E2E 和真实 SDK 视觉验收。

本批不包含：统计中心、瓦斯正式数据接入、AI 预测、iServer 自动发布、真实 CRS 配准和任意斜剖面。

## 2. 数据源合同

电阻率源文件为项目外部的标准化 CSV，逻辑身份为 `地下电阻率节点_标准化.csv`，不将本机绝对路径或私有文件提交 Git。运行时登记文件 SHA-256，CI 使用脱敏夹具和固定合同，不依赖用户本机数据。

已核验的源事实：

| 项目 | 合同 |
|---|---|
| 字段 | `X,Y,Z,RHO` |
| 行数 | 17,549 |
| 坐标 | 局部工程坐标，未声明 EPSG |
| 坐标唯一性 | `(X,Y,Z)` 无重复 |
| 数值 | 坐标和值全部有限 |
| RHO 范围 | 约 1.032113 至 149.984 |
| 空间结构 | 293 个 `(X,Y)` 空间柱，每柱 42 至 60 个节点 |

标准化源的训练/验证分区继续使用既有空间柱合同：训练 15,827 行、验证 1,722 行，交叉空间柱数为 0。分区、源 SHA、字段映射、值单位声明和坐标类型必须写入数据版本 profile，并参与数据版本指纹。

## 3. 案例迁移

案例 ID 继续使用 `resistivity`，以保持现有深链可解析；案例公开身份从 `builtin_legacy` 变为 `builtin_preset`，数据版本为只读预置版本，不提供 CSV 上传步骤。

迁移顺序：

1. 校验源文件身份、字段、行数、有限性、坐标唯一性和空间柱分区。
2. 创建只读预置数据版本并写入完整 profile。
3. 按生产执行链重建官方 Kriging 基线，创建 `Experiment → Run → CandidateResult → materialize → FormalSelection` 链。
4. 运行 IDW、Kriging、DSI-like 的最小官方候选集合，确认指标和成果身份可追溯。
5. 生成新的 NetCDF/RenderAsset，并以真实浏览器验证 Volume、X/Y/Z Slice、Contour 和剖面链。
6. 新链验证通过后，停用旧 legacy/S3M 产品代码和用户入口。

旧 S3M 文件、旧数据库记录和旧证据在新链验收前保留，但不再出现在首页、工作台、成果列表或默认渲染路径。新链验收后，旧资产清理由单独的迁移清理任务执行，不与算法提交混在一起。

旧兼容 API 不静默返回旧成果；直接访问时返回明确的 `LEGACY_RESISTIVITY_RETIRED` 状态或等价类型化错误，避免用户误认为仍在使用旧模型。

## 4. DSI-like 算法合同

### 4.1 定位

产品名称固定为“DSI-like 离散平滑插值”。它是基于 IDW 初始场和离散邻域平滑的 Python 工程近似方法，不宣称等同 GOCAD DSI，也不宣称给出唯一真实地质结构。

### 4.2 计算流程

1. 使用现有 IDW 适配器和实验网格合同生成初始规则网格。
2. 根据规则网格邻接关系，对非观测节点执行加权 Jacobi 平滑。
3. 每轮重新写入观测点原值，观测点硬约束始终开启。
4. 仅在观测点三维包围范围内更新节点；外部节点保持 NoData。
5. 在达到最大迭代次数或最大节点变化低于收敛容差时停止。
6. 对输出执行有限值、覆盖率、观测点误差和 NoData 掩膜校验。

空间验证时，每个折只使用训练点重建初始场和平滑场，验证点不能进入硬约束集合。验证点预测通过同一网格采样合同得到，并继续使用现有 RMSE、MAE、R²、Bias 和公共有效集规则。

### 4.3 参数与指纹

| 参数 | 允许值/默认值 | 说明 |
|---|---|---|
| `init_power` | `1.5 / 2.0 / 3.0`，默认 `2.0` | IDW 初始化幂次 |
| `neighbor_connectivity` | `6 / 18 / 26`，默认 `6` | 规则网格邻接方式 |
| `smoothing_strength` | `0.25 / 0.5 / 0.75`，默认 `0.5` | 平滑更新强度 |
| `max_iterations` | `25 / 50`，默认 `25` | 最大迭代次数 |
| `convergence_tolerance` | 固定 `1e-4` | 最大节点变化停止阈值 |
| `hard_constraints` | 固定 `true` | 不允许用户关闭 |

算法无随机种子。数据版本指纹、空间折分指纹、网格规格和全部参数共同决定候选指纹；相同输入必须产生相同预测和网格字节。

### 4.4 失败语义

- 输入不是已验证三维散点数据：拒绝创建实验；
- 坐标或值出现非有限值、重复坐标或公共有效集为空：类型化失败；
- 迭代出现非有限值或未通过收敛/覆盖率门：候选为 `failed`，不得物化；
- 不在观测包围范围内的网格不得被静默填值；
- DSI-like 不可用时不得回退为“看起来成功”的 IDW 或点云渲染。

## 5. 统一产品流程

首页电阻率卡片展示“标准化散点 · 17,549 个节点”，字段为 `X/Y/Z/RHO`，并显示局部工程坐标。用户点击后直接进入统一案例工作台，不经过 CSV 导入或 legacy 页面。

新建实验的算法选项为：

- IDW；
- 普通 Kriging；
- DSI-like 离散平滑插值。

DSI-like 选项旁显示简短说明：“基于 IDW 初始场和离散邻域平滑的工程近似方法，不等同于 GOCAD DSI。”

候选排行榜只能比较同一数据版本、同一空间折分、同一网格合同下的候选。成果页、Volume、X/Y/Z Slice、Contour、剖面分析和导出全部复用现有统一组件，不新增电阻率专用渲染器。

## 6. 后端与资产边界

- 预置源通过只读 seed 建立，不能被用户上传、覆盖或正式选择改写；
- 官方结果和用户实验继续分离，预置官方正式选择不可被用户候选顶替；
- 所有候选继续通过 `CandidateResult → materialize → NetCDF → RenderAsset`；
- NetCDF manifest 必须包含源 SHA、数据版本指纹、算法、参数、网格规格和 provenance；
- 旧 legacy source resolver 不再参与新电阻率工作台；
- 旧资产在迁移完成前只读保留，不可作为新候选或默认 featured result。

## 7. 验收合同

### 数据与算法

- 源文件合同测试覆盖 17,549 行、字段、有限性、坐标唯一性和空间柱分区；
- DSI-like 合成三维场测试覆盖确定性、硬约束、邻接方式、收敛和非有限值拒绝；
- 训练/验证测试证明验证点未进入硬约束集合；
- 电阻率真实源至少生成一组成功的 DSI-like 候选，指标可复算；
- IDW、Kriging、DSI-like 候选的比较合同和 R² null 语义不回归。

### 产品与视觉

- 电阻率与微震工作台路由、卡片和操作语义一致；
- 无旧 legacy/S3M 用户入口、重复卡片或误导性旧术语；
- 三种算法均可创建实验、查看候选、生成 NetCDF 和进入成果页；
- 真实 SDK 浏览器验证 Volume、X/Y/Z Slice、Contour、光照、透明度、色带和剖面入口；
- warm-cache、普通刷新和服务重启场景均不得出现黑屏或旧资产缓存；
- 桌面和 390x844 移动端无横向溢出，按钮和状态均有可访问名称。

### 发布门

- 后端便携测试、前端 Vitest、类型检查、构建、Mock E2E 和 platform-live 全绿；
- 真实 GPU live 门至少覆盖电阻率散点、微震预置和一个用户上传三源；
- 证据 JSON 使用干净提交身份，源文件绝对路径、私有数据、运行库和凭据零入库；
- 只有新链完整验收后，才允许执行旧 legacy/S3M 清理任务。

## 8. 明确不做的事情

- 不把电阻率旧规则网格反向伪装成 DSI 输入；
- 不把 DSI-like 宣称为官方 DSI 或 GOCAD 结果；
- 不在浏览器实现插值公式；
- 不用旧 S3M 结果冒充新散点候选；
- 不把旧资产物理删除和新算法实现放在同一个不可回滚提交中；
- 不在本批加入统计中心、瓦斯、AI 或 iServer 自动发布。
