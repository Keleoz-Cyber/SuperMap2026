# v0.6.1 NetCDF Native Volume Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Starting from tag `v0.6.0`, make SuperMap3D 12.1 `VoxelGridLayer3D + NetCDF classic/v3` the only product volume renderer, keep point data only as explicitly labeled auxiliary layers, and remove the custom WebGL2 ray-marching product route.

**Architecture:** FastAPI owns immutable render-source identity, deterministic NetCDF generation, persisted render-asset state, and read-only asset delivery. Vue owns business and control state; an isolated same-origin iframe owns the SuperMap3D 12.1 global runtime and draws both the NetCDF volume and auxiliary points after applying one `wgs84_display_anchor_v1` display transform. Native renderer failures are fail-closed and never switch to points or another volume renderer.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy/SQLite schema v6, NumPy, SciPy `scipy.io.netcdf_file`, Vue 3, TypeScript, Element Plus, SuperMap3D 12.1, Vitest, Playwright, pytest.

## 0. Read This Before Editing

### 0.1 Fixed product decisions

These decisions are requirements, not implementation options:

1. `VoxelGridLayer3D + NetCDF` is the only continuous-volume renderer shown by the product.
2. Point primitives are auxiliary sampling/evidence layers. UI, tests, evidence, and docs must not call them "volume", "voxel rendering", or a fallback renderer.
3. A 3D result supports volume rendering only when its persisted artifact is a finite, strictly increasing, approximately regular Cartesian grid with at least two nodes on every axis.
4. A 2D result, irregular grid, missing grid, or legacy case without a registered immutable regular-grid source reports `supported=false` with a stable reason code.
5. A native-render failure remains an explicit error. Auxiliary points may remain visible only if the user had enabled them; their presence must not change the failed volume state.
6. The parent Vue page and iframe are same-origin but use separate JavaScript globals. Do not load old `Cesium` and SuperMap3D 12.1 into the same window.
7. Both volume and points use `wgs84_display_anchor_v1`. The UI must display `display_anchor_only`; it must not claim real georeferencing.
8. `opaqueRate` is not an effective opacity control in the verified SDK build. Rebuild `opacityTransferFunction` when overall opacity changes.
9. Do not reintroduce GeoTIFF, iDesktopX `DatasetVolume`, S3M carriers, Three.js, or custom shaders as a hidden fallback.
10. The gas case remains parked and outside v0.6.1 formal NetCDF coverage.

## 2. Stable Contracts

### 2.1 Render source

Use this internal contract in `render_contracts.py`:

```python
from dataclasses import dataclass
from pathlib import Path
from typing import Literal

SourceKind = Literal["candidate_result", "builtin_legacy"]

@dataclass(frozen=True)
class RenderGridSource:
    source_kind: SourceKind
    source_id: str
    grid_path: Path
    grid_sha256: str
    property_name: str
    units: str
    coordinate_kind: str
    dimension: Literal["3d"]

@dataclass(frozen=True)
class ValidatedGrid:
    axes: tuple[np.ndarray, np.ndarray, np.ndarray]
    values: np.ndarray
    is_nodata: np.ndarray
    valid_min: float
    valid_max: float

@dataclass(frozen=True)
class DisplayAnchor:
    longitude: float = 120.0
    latitude: float = 30.0
    height: float = 0.0
    contract: Literal["wgs84_display_anchor_v1"] = "wgs84_display_anchor_v1"
    geolocation_status: Literal["display_anchor_only"] = "display_anchor_only"
```

`property_name` comes from dataset profile `mapping.value_name`; `units` comes from `mapping.value_unit` and becomes the literal string `"unknown"` only when source metadata is absent. NetCDF variable names are safe identifiers derived from `property_name`, not fixed to `rho`.

Normalization:

```python
def netcdf_variable_name(property_name: str) -> str:
    normalized = re.sub(r"[^A-Za-z0-9_]", "_", property_name.strip())
    if not normalized or normalized[0].isdigit():
        normalized = f"value_{normalized}"
    return normalized[:64] or "value"
```

Rules:

- POST is the only operation that may materialize a result or create/retry an asset.
- GET capability, status, manifest, NetCDF, result metadata, preview, and slices never create files or mutate rows.
- First successful POST returns 201. Idempotent reuse returns 200. An existing `creating` row returns 409 `RENDER_ASSET_IN_PROGRESS`.
- A failed row is retried only when POST body is `{"retry_failed": true}`; otherwise return the persisted failure with 409.
- File GETs require a database row in `ready`, revalidate containment under `render-assets`, and verify current file hash before serving.

### 2.4 Parent/iframe protocol

Protocol name: `gmp-supermap-volume/v1`.

Shared TypeScript types:

```ts
interface DisplayTransform {
  contract: 'wgs84_display_anchor_v1'
  origin_x: number
  origin_y: number
  anchor_longitude: number
  anchor_latitude: number
  anchor_height: number
  metres_per_degree_lon: number
  metres_per_degree_lat: number
}

interface RenderAssetRecord {
  id: string
  source_kind: 'candidate_result' | 'builtin_legacy'
  source_id: string
  renderer: 'supermap_voxelgrid_netcdf'
  status: 'creating' | 'ready' | 'failed' | 'interrupted'
  grid_sha256: string
  netcdf_sha256: string | null
  manifest_url: string | null
  netcdf_url: string | null
  error: { code: string; message: string; details: Record<string, unknown> } | null
}

interface RenderIdentity {
  sourceKind: 'candidate_result' | 'builtin_legacy'
  sourceId: string
  gridSha256: string
  netcdfSha256: string
}

interface PointLayerPayload {
  id: 'grid-samples' | 'aggregated' | 'accepted' | 'rejected' | 'legacy-measurements'
  visible: boolean
  role: 'auxiliary' | 'evidence'
  coordinates: 'local'
  x: number[]
  y: number[]
  z: number[]
  values?: number[]
  isNodata?: boolean[]
  style: { color?: string; pixelSize: number; outlineColor?: string; outlineWidth?: number }
}
```

Parent messages:

```ts
type ParentMessage =
  | { protocol: 'gmp-supermap-volume/v1'; type: 'INIT'; requestId: string; asset: RenderAssetRecord | null; displayTransform: DisplayTransform }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'SET_MODE'; requestId: string; mode: 'volume' | 'slice' | 'contour' }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'SET_FILTER'; requestId: string; min: number; max: number }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'SET_OPACITY'; requestId: string; opacity: number }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'SET_POINT_LAYER'; requestId: string; layer: PointLayerPayload }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'RESET_VIEW'; requestId: string }
```

Child messages:

```ts
type ChildMessage =
  | { protocol: 'gmp-supermap-volume/v1'; type: 'FRAME_READY'; requestId: string; sdkVersion: string; contextType: number }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'RENDER_STATE'; requestId: string; phase: 'loading' | 'rendered' | 'failed' | 'unsupported'; identity: RenderIdentity | null }
  | { protocol: 'gmp-supermap-volume/v1'; type: 'ERROR'; requestId: string; code: string; message: string }
```

Both sides must require:

```ts
event.origin === window.location.origin
event.source === expectedWindow
message.protocol === 'gmp-supermap-volume/v1'
message.requestId === activeRequestId
```

Use `window.location.origin` as `postMessage` target origin; never `"*"`. The iframe accepts only relative manifest/NetCDF paths beginning `/api/render-assets/`.

The parent creates the iframe URL as:

```text
/supermap-volume-frame/index.html?request_id=<URL-encoded random request ID>
```

The child parses and validates that query value before emitting `FRAME_READY`, which solves the initial handshake without accepting an uncorrelated message. `INIT` with `asset=null` is point-only initialization: the viewer may draw auxiliary layers, but it emits `phase="unsupported"` and never `rendered`.

## 3. Release Acceptance Checklist

The implementation is complete only when every item below is true:

- [ ] Generic 3D and microseismic candidate grids create deterministic NetCDF v3 assets.
- [ ] Variable/property/unit metadata is generic; no production path fixes the variable to `rho`.
- [ ] 2D, irregular, absent, and all-NoData sources fail with stable capability/error codes.
- [ ] Legacy resistivity cannot claim volume support until an authoritative grid is registered.
- [ ] POST is the only asset-creation path; all GET routes are pure queries.
- [ ] A ready DB row can never expose a partially copied NetCDF.
- [ ] Manifest, grid, and NetCDF hashes are checked before browser rendering and before file delivery.
- [ ] Vue owns business state and controls; SuperMap3D runs only in the same-origin iframe.
- [ ] Point and evidence layers use the same display transform as the volume.
- [ ] Points are labeled auxiliary and cannot turn a failed volume into success.
- [ ] `/volume-demo`, custom shaders, Three.js/custom ray marching, old `Field3D`, and old `RhoScene3D` are absent from product code.
- [ ] No old `Cesium` global is loaded in the Vue parent.
- [ ] The real SDK hash and complete resource tree are preflighted.
- [ ] Volume, filter, opacity, Slice, and Contour have machine-checked pixel response.
- [ ] 32-cubed and 64-cubed pass the 30-second render and 5-second interaction gates on the reference machine.
- [ ] Evidence metadata comes from one run and contains no mixed GPU/viewport identities.
- [ ] Existing slice, formal selection, export, publication, professional analysis, and microseismic evidence workflows still pass.
- [ ] Full backend, frontend unit, type, build, mock E2E, and local real-SDK E2E pass.

## 4. Explicit Non-Goals

- Real-world CRS/georeferencing without control-point evidence.
- WebGPU `contextType=3`.
- 128-cubed production support.
- iServer/S3M distribution or iDesktopX `DatasetVolume`.
- Mobile browser support.
- Automatic reconstruction of the built-in resistivity formal grid from scattered measurements.
- A fallback volume renderer of any kind.
