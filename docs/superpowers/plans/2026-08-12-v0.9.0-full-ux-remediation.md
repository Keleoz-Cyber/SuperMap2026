# v0.9.0 Full UX Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve every issue recorded by the 2026-08-12 full-route UX audit while preserving modeling, analysis, rendering, and evidence contracts.

**Architecture:** Keep the Vue 3 router, API DTOs, Element Plus controls, ECharts panels, and SuperMap iframe intact. Replace unstable global navigation with a context-independent shell, add shared user-facing identity/summary helpers, and rebuild each route around one task, one primary action, progressive disclosure, and mobile-specific composition.

**Tech Stack:** Vue 3, Vue Router, TypeScript, Element Plus, ECharts, Vitest, Playwright, FastAPI.
