## 2. 单一全局应用壳

### 2.1 顶部栏

- 所有路由始终使用同一个 `AppHeader`，成果页不再隐藏全局头，也不再渲染 `V6ResultTopbar`。
- 品牌 Logo 是回到首页的唯一固定首页入口，主导航不重复显示“首页”。
- 桌面主导航固定为：
  1. 数据接入
  2. 建模实验
  3. 模型比较
  4. 成果空间
- 主导航使用真实链接；缺少案例、数据集、实验或成果上下文时显示明确禁用原因，不构造虚假 ID。
- 页面专属主动作通过 shell context 注入右侧动作位。例如成果页显示案例切换与“导出分析报告”，普通页面显示“导入数据”。
- 服务状态、版本与回收站降为次级信息；不得挤压主导航。窄屏下按优先级收起为图标或菜单。

### 2.2 统一页面上下文标题

- 新建 `PageContextHeader`，统一承载：简短面包屑、唯一 H1、副标题/身份摘要、页面主动作。
- 页面不能同时出现全局上下文、重复面包屑和第二个同义 H1。
- 沉浸式成果页使用全宽标题带；表单/列表页使用标准内容宽度，但左右边界必须与顶栏内容网格对齐。

## 4. 案例工作台阶段标签

- 四阶段改为真正的标签页，一次只渲染当前阶段内容，不再依赖 `scrollIntoView`。
- 当前阶段写入查询参数 `?stage=data|experiments|results|evidence`，刷新、分享、前进和后退均可恢复。
- 标签使用语义化 `button`，支持键盘左右方向键切换、可见焦点和正确 `aria-selected`。
- 禁用阶段继续显示原因；点击禁用项不切换内容。
- 原有按钮、实验记录、成果链接、分析入口和溯源文案全部保留，不因版式改造而丢失功能。

## 5. 全站版式合同

### 5.1 内容网格

- 建立统一 token：页面水平留白、标准内容最大宽度、密集工作台宽度、卡片间距、标题间距。
- 标准页面在 1920px 下不允许内容只占右半屏；内容区居中且与顶栏网格对齐。
- 沉浸式成果页全宽，但工具栏、三维场、分析栏和证据窗使用明确的 grid/flex 约束。
- 禁止依靠缩小字体解决空间不足；成果工作台局部最小字号保持 12px，正文主要使用 13–16px。

### 5.2 间距与空白

- 同级卡片使用统一 gap；标题与内容之间不得小于一个基础间距。
- 空白必须用于建立层级，不得因固定高度、错误 `max-width`、孤立 `margin:auto` 或未填满的 grid 列产生大片无意义区域。
- 长 ID 与来源信息使用截断、换行或“数据溯源”专页，不得撑破布局。

### 5.3 交互与可访问性

- 导航使用链接，动作使用按钮；不能存在“只变色但无结果”的伪交互。
- 图标按钮提供 `aria-label`，表单控件有标签，交互元素有 `:focus-visible`。
- 状态标签和数字列使用稳定对齐；数字使用等宽数字。
- 动画只使用 transform/opacity，并遵守 `prefers-reduced-motion`。

## 6. 成果证据窗

- 工作台保持一屏模式，整页不恢复纵向滚动。
- 证据内容区使用 `flex: 1; min-height: 0; overflow-y: auto`，父级隐藏越界内容，确保可以滚到真正末尾。
- 默认高度为 `clamp(280px, 29vh, 330px)`。
- 增加“展开分析/收起分析”：展开态约占工作台可用高度 52%，切换不卸载三维 iframe，不丢失相机、切片、筛选和聚焦状态。
- 低高度或窄屏回退为普通页面流，避免固定高度互相挤压。

## 7. 渲染默认状态

- `NativeVolumePanel` 首次状态、能力加载后重置、资产身份切换后重置均明确设置：
  - `lighting: false`
  - `gradientOpacity: false`
- 后端 profile 继续决定能力、色带、标度、值域、包围盒和总体透明度，但不决定这两个首次显示开关。
- 用户可手动打开；重新载入或切换成果时回到关闭状态。

## 8. 首页调试信息清理

- ready 资产不显示“刷新状态”。
- 首页官方成果预览不显示资产 ID、网格 SHA、NetCDF SHA、坐标契约和渲染身份调试块。
- 创建失败、资产失败或中断时仍保留错误诊断和重试动作。
- 成果页“数据溯源”继续保留正式资产身份与哈希，不丢失证据能力。

## 9. AI 辅助研判的用户化表达

- “快速解读”用于提炼主要结论、关键依据和下一步动作；“深度复核”额外检查证据矛盾、解释边界和过度结论。两种模式必须显示说明文字。
- 切换模式只读取对应模式的历史记录，不得显示另一模式的结果，也不得自动触发外部付费请求；没有记录时显示模式专属生成入口。
- 主阅读顺序固定为：一句话结论 → 三项关键判断 → 建议先做 → 方案比较 → 分歧与限制。
- `result_grid`、`depth_profile`、`component-N` 等证据 ID 不直接面向用户展示，转换为“成果网格”“深度趋势”“异常区域 A”等中文名称并收进可展开的“查看数据依据”。
- provider、model、prompt version、evidence hash 收进“技术信息”；正文不使用内部合同术语制造专业感。
- 正文不小于 14px，关键判断与动作不小于 15px，模式按钮必须同时说明用途，不能只写“快速/复核”。

## 10. 路由覆盖范围

逐页复核首页、回收站、案例工作台、案例创建、数据上传、数据准备、新建/详情实验、专业诊断、专业分析、模型比较、统计与空间分析、成果空间。兼容重定向路由不单独设计页面。

答辩模式保持退役状态：不注册 `/presentation` 路由、不显示入口，也不保留第二套展示壳。旧深链继续由兜底路由返回首页。

## 11. 验收矩阵

### 11.1 自动化合同

- 单元测试证明：后端 profile 即使返回两个开关为 `true`，首次渲染状态仍为 `false`。
- 案例标签切换内容并同步 URL；刷新和前进后退恢复阶段。
- 证据窗默认、展开和收起状态正确，场景组件实例不被重建。
- 所有页面只存在一个全局顶栏、一个 H1，旧 `V6ResultTopbar` 不再渲染。
- 页面用词扫描拒绝用户可见的“模型对比”等旧词。
- AI 最新记录按 `quick|review` 隔离读取；模式切换不产生 POST；用户界面不直接显示内部证据 ID。

### 11.2 真实浏览器视觉门

在 1920×1080、1440×900、1366×768 下逐页检查：

- 无横向溢出、控件遮挡、文字裁切和不可达滚动末尾；
- 顶栏高度、品牌、主导航和标题基线一致；
- 页面左右边界与内容网格一致；
- 主要内容不因旧容器集中于半屏；
- 默认光照和渐变透明度未选中；
- 证据窗默认可见核心图，展开后可浏览全部内容；
- 案例四阶段点击产生明确内容变化；
- 首页指定调试块消失；
- AI 两种模式显示不同说明和各自记录；结论与建议动作在首屏可识别，技术信息默认折叠；
- 控制台 error、pageerror 与未解释网络失败均为零。

390×844 仅要求不横向溢出、核心导航可达和内容可读，不强制复制桌面一屏布局。

## 12. 非目标与边界

- 不改后端分析指标、数据口径、三维几何比例或正式成果身份。
- 不恢复答辩模式；本轮还需验证其路由、入口和专用壳均未复活。
- 不把调试信息改写成分析结论。
- 不删除失败恢复能力。
- 不合并 PR、不打标签、不创建 Release。
