# v0.8.0 第三批瓦斯预置案例 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `example_data/瓦斯含量_合格样品.csv` 接入统一 `builtin_preset` 案例链，并统一三案例默认源路径、单位、差异化分析与 NetCDF 真实渲染验收。

**Architecture:** 复用现有微震/电阻率预置 seed 与统一 Case→Dataset→Experiment→Run→Candidate→NetCDF→RenderAsset 链，新增瓦斯专属 profile/分析载荷；源文件由项目根目录解析器从 `example_data/` 提供，浏览器只接收逻辑来源与哈希。DSI-like 是条件候选，不绕过现有验证、物化和渲染门。

**Tech Stack:** Python 3.11、FastAPI、Pydantic、SQLite/SQLAlchemy、NumPy/Pandas、Vue 3、ECharts、Vitest、Playwright、真实 SuperMap3D SDK。
