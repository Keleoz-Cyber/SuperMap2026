# 电阻率 DSI-like 本机证据落点

该目录只保留本机真实 SDK 测试的输出约定，不保留历史重复运行截图。

`web/e2e-live/resistivity-scattered-live.spec.ts` 和 `warm-cache-upgrade-live.spec.ts` 会使用 `example_data` 与 `seed-resistivity`，并在这里生成以 `run_id` 命名的 `run-*` 临时目录。身份文件必须登记 40 位 `git_commit`。`run-*` 默认被 Git 忽略；只有完成身份、控制台、网络、像素和提交祖先检查后的代表性证据才允许人工纳入当前版本证据目录。

当前正式答辩证据见 `docs/evidence/v0.9.0/`。
