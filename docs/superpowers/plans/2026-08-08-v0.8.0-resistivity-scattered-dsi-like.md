# v0.8.0 电阻率散点与 DSI-like Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将电阻率标准化 CSV 迁移为统一的只读散点预置案例，并把可验证的 DSI-like 离散平滑插值接入现有实验、候选、NetCDF 和渲染链。

**Architecture:** 保留 `resistivity` 案例 ID，但由 `builtin_legacy` 迁移为 `builtin_preset`。新增一个独立的源加载器和一个符合现有 `Interpolator` protocol 的 `DSILikeInterpolator`；runner、候选、物化和渲染继续复用现有生产链。旧 S3M/legacy 资产在新链验收前只读保留，新链验收后通过单独清理提交移除用户入口和旧运行时资产。

**Tech Stack:** Python 3.12、Pydantic、NumPy、SciPy、pandas、SQLAlchemy/SQLite、FastAPI、Vue 3、TypeScript、Vitest、Playwright、真实 SuperMap3D SDK live 门。

class DSIParameters(ContractModel):
