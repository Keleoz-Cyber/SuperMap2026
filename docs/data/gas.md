# 煤层瓦斯数据与三维实验状态

> 更新时间：2026-07-22。本文记录当前项目采用的瓦斯数据规则、派生文件和SuperMap失败证据。原DOC、DEM和派生CSV均位于相邻只读目录`../超图杯资料`，不提交Git。

## 1. 原始与标准化记录

- 原始来源：`2025-刘昌佳-煤层瓦斯分析成果表（表4-13）.doc`；
- 标准化总记录：76条、29组坐标；
- 原始质量状态：58条“合格”、18条“不合格”；58条“良好”、16条“漏气”、2条“漏气、漏水”；
- `BH001`—`BH029`是标准化生成的位置ID，不是原始孔号。

漏气、漏水和不合格状态不能通过插值修复。当前三维候选只采用已登记为合格的58条记录，覆盖28个位置；被排除记录仍保留在标准化表中供追溯。

## 2. 坐标与Z规则

当前项目采用以下已确认工作约定：

- 大地基准：西安1980；
- 投影：6°高斯—克吕格；
- 分带：第20带；
- 中央经线：117°E；
- 带号东坐标工作标识：EPSG:2334；
- CSV轴顺序：`X`为约2,000万的带号东坐标，`Y`为约380万的北坐标。

`采样止深`不是绝对Z。现有三维候选使用DEM派生地表高程和采样区间中点：

```text
MID_DEPTH = END_DEPTH - THICKNESS / 2
Z = SURF_Z - MID_DEPTH
```

该规则采用垂直钻孔近似。DEM来源、垂直基准和钻孔轨迹尚未在代码中验证，因此成果必须标为“瓦斯三维候选/实验”，不能描述成已完成的精确煤层几何模型。

## 4. SuperMap实验结果

- 三维点`GAS_CH4_POINTS_3D_58`可以加入真正的平面三维场景并正常显示；
- 已生成IDW体元`GAS_CH4_IDW_R1000_N12_P1`；
- 将该体元加入平面或球面三维场景都会导致iDesktopX 2026原生崩溃；
- 最新崩溃栈位于`Layer3DNative.jni_SetSliceCoordinate`、`Layer3DSettingVolume.setSliceCoordinate`、`Layer3Ds.add`；iObjects日志同时出现体元XML信息为空。

现有证据只能定位到“当前体元元数据/本机iDesktopX体元加载链路不兼容”，还不能区分数据集元数据异常与产品缺陷。不得继续通过反复换CRS来解释或规避该崩溃。

## 5. 开发决策

- 瓦斯保留为第三个独立案例和通用三维接口测试数据；
- 当前不作为首个iServer/Web演示闭环，不阻塞电阻率和微震开发；
- 平台主干完成后，用极小体元、重新生成体元和S3M/三维缓存发布分别做隔离测试；
- Web正式展示优先验证iClient3D体渲染/采样路线，不假定UDBX体元可直接在浏览器加载；
- 任何瓦斯正式成果必须同时记录质量筛选、属性字段、DEM/垂向基准、Z规则、插值参数和渲染证据。
