# Kimi 3 开发交接包设计说明

> 版本：0.1
> 日期：2026-07-18
> 状态：已由项目负责人确认
> 适用范围：第一版电阻率三维属性模拟 MVP，以及后续微震、煤层瓦斯模块的接口预留

## 1. 设计目标

将现有论文、原始数据、标准化数据、SuperMap 实验结果和项目判断整理成一套能够直接驱动代码开发的输入。交接包必须让开发者能够回答：系统第一版做什么、数据从哪里来、字段怎样解释、哪些结果已经验证、哪些结论仍不能使用，以及怎样判断开发成果是否合格。

交接包不是资料备份，也不替代原始论文。原始资料继续保存在 `参考资料` 中并保持只读；交接包通过相对路径引用来源，只记录开发需要的结论、规则和证据。

## 2. 方案比较与选型

### 方案 A：直接交付全部原始资料

优点是准备工作少；缺点是开发者必须自行判断论文冲突、字段含义和数据质量，容易把推断写成业务规则，也难以建立可重复的验收过程。本项目不采用。

### 方案 B：最小可执行交接包

先交付项目总览、MVP 功能清单、数据契约和已知问题四份核心文档，并引用已经标准化的数据与验证报告。开发可以先搭建工程骨架、电阻率闭环和测试框架；微震与瓦斯在数据契约确认后逐步接入。

该方案准备成本适中，能够尽早启动代码开发，同时保留科学规则的人工审核。本项目采用此方案。

### 方案 C：全部研究和多源融合完成后再开发

优点是资料最完整；缺点是会让界面、数据读取、任务管理和成果导出等基础工程长期等待，也容易在需求尚未验证时过度设计。本项目暂不采用。

## 3. MVP 边界

第一版只打通地下电阻率数据的完整链路：

1. 读取标准化 `X,Y,Z,RHO` 数据；
2. 校验字段、数量、坐标范围、数值范围和缺失值；
3. 管理训练集、验证集和插值参数；
4. 调用或接收 SuperMap 普通克里金、IDW 结果；
5. 展示完整体元、水平切片、垂直切片和阈值异常区；
6. 输出模型元数据、质量指标、操作记录和成果文件清单。

以下内容不作为第一版阻塞项：

- 微震 DSI-like 算法的正式实现；
- 煤层瓦斯的可信三维叠加；
- GOCAD 工程解析；
- 自动成矿概率或储量计算；
- 断层、地层接触关系和复杂非结构网格；
- 对外发布服务和多人权限管理。

这些能力必须通过独立模块和稳定接口后续加入，不能混入第一版电阻率闭环。

## 4. 系统边界与模块

### 4.1 数据层

负责原始数据索引、标准化数据读取、字段校验、版本标识和数据质量标记。不同阶段的数据必须分开保存：

```text
原始观测 -> 标准化数据 -> 训练/验证数据 -> 插值成果 -> 可视化派生物
```

任何派生步骤都不得覆盖上一步数据。

### 4.2 算法与验证层

负责插值任务参数、预测结果采样、公共有效点对齐以及 MAE、RMSE、R²、偏差、对数误差和覆盖率计算。算法选型依据统一验证结果，不依据单张图面的平滑程度。

第一版主选 `Kriging 20m/40点`，因为其 MAE、中位绝对误差和平均相对误差更优；同时必须保留 `IDW 20m/25点` 作为对照，因为后者 RMSE、R² 和对数误差略优。系统界面和报告不得描述普通克里金在所有指标上都优于 IDW。

### 4.3 SuperMap 集成层

SuperMap 负责三维点和体元栅格管理、场景表达、切片、属性查询、阈值过滤和成果输出。外部代码负责数据准备、质量校验、结果登记和可复现记录。

代码层不应依赖人工界面中临时生成的数据集名称。每个模型应通过配置记录数据源、数据集名称、参数、生成时间和输入文件哈希。

### 4.4 后续算法接口

微震 DSI-like、GOCAD DSI、普通克里金和 IDW 应输出统一的三维节点与模型元数据。DSI 结果进入 SuperMap 时不得再次使用 IDW 或克里金改变其数值场；规则网格优先通过统一切片或直接体元格式载入。

## 5. 数据流与错误处理

### 5.1 正常数据流

```text
标准化 CSV
  -> 数据契约校验
  -> 训练/验证划分或正式模型输入
  -> 插值/模型生成
  -> 预测值或体元成果登记
  -> 质量评估
  -> SuperMap 场景与切片
  -> 成果清单和审计记录
```

### 5.2 必须阻断的情况

- 字段缺失、字段类型错误或记录数与清单不一致；
- 坐标单位、Z 方向或 NoData 规则没有配置；
- 训练集和验证集存在空间柱交叉；
- 插值成果与验证点无法按坐标正确对应；
- 算法结果含非有限数值或超出允许范围且无说明；
- 将空数据集、失败任务或仅有图面效果的场景登记为正式成果。

### 5.3 可以继续但必须警告的情况

- 模型覆盖率不足 100%；
- 不同指标给出不同的模型优胜结论；
- 异常区接触插值边界；
- SuperMap 当前版本无法执行某项批处理，只能通过外部脚本完成；
- 微震或瓦斯缺少完整绝对坐标条件，只能做相对模型或属性统计。

## 6. 已确认的数据与验证基线

### 6.1 电阻率

- 标准文件：`../../../超图杯资料/标准化数据/地下电阻率节点_标准化.csv`
- 字段：`X,Y,Z,RHO`
- 记录数：17,549
- 训练集：15,827 条、264 根空间柱
- 验证集：1,722 条、29 根空间柱
- 训练集与验证集空间柱交叉数：0
- 五种候选模型公共有效验证点：1,481
- 公共 NoData：241
- 公共覆盖率：约 86.0%
- 当前正式候选：`Kriging 20m/40点`
- 当前 SuperMap 全量体元：`RHO_KRIG_FINAL_20M_40`
- 已验证表达：完整体元、水平薄切片、`RHO >= 77` 高值过滤

### 6.2 微震

- 原始深度—速度文件：22 个
- 原始数值记录：2,005 行
- 研究主线测线：L1、L2、L3
- L3 标准测点：W24—W27；W28 不进入当前标准模型
- 当前限制：完整三维坐标仍需通过测线相对几何、点间距和 Z 方向约定重建

### 6.3 煤层瓦斯

- 样品记录：76 条
- 坐标组：29 组
- 当前限制：仅标记“80系”，未确认完整 CRS、坐标轴顺序、孔口高程和采样深度基准
- 使用边界：可以做属性统计；在条件确认前不得与电阻率、微震强行进行可信三维叠加

## 7. 当前已知问题

1. 五种电阻率模型均有相同的 241 个无预测值，不能无依据补值。
2. SuperMap 原生等值面提取在 77 单值及 77—133.146 值域均失败，两个结果数据集为空。
3. `RHO >= 77` 高值异常触及体元顶部、底部或侧边界；补一层或两层低值边界体元后重新提取等值面是待验证方案，不是已确认修复。
4. 电阻率正式体元 X 向仅 7 个单元，异常体几何较粗，不能把视觉边界解释为精确地质界面。
5. 微震数据的相对坐标可以建模，但不能虚构绝对地理坐标。
6. 煤层瓦斯数据在 CRS 和高程条件补齐前不能进入三维融合主线。
7. 当前资料缺少实际 GOCAD `.sg`、Voxet、VTU 或论文所述 DSI 输出，无法验证真实 GOCAD 到 SuperMap 的端到端转换。

## 9. 验收标准

交接包第一版完成时应满足：

- Kimi 3 不阅读全部论文，也能确定 MVP 输入、输出、模块边界和验收方式；
- 每个关键数据数字都能追溯到标准化文件或验证摘要；
- 已确认事实、工程选型、推断和待确认事项明确区分；
- 原始资料没有被移动、改名或覆盖；
- 文档路径有效，不包含失效的相对链接；
- 不出现未定义缩写、无解释阈值或无法测试的模糊要求；
- 后续微震、瓦斯和 DSI 模块可以通过统一数据接口加入，而无需重写电阻率 MVP。

## 10. 已确认的产品决策

项目负责人已经确认两项产品决策：

1. 第一版系统是否明确以“电阻率三维属性模拟闭环”为 MVP，而不是同时完成三类数据融合；
2. `Kriging 20m/40点` 是否作为默认展示模型，同时在系统和报告中保留 `IDW 20m/25点` 对照及两者指标差异。

四份正式交付文档及其实施计划已经生成，后续开发以这些文档为依据。
