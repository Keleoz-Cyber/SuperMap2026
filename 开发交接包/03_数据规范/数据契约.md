# 地矿属性模拟系统数据契约

> 契约版本：0.1
> 日期：2026-07-18
> MVP 主数据：地下电阻率
> 适用范围：文件校验、模型任务、SuperMap 成果登记和后续算法交换

## 1. 基本原则

1. 原始观测只读，任何清洗、拆分、插值和可视化都生成新数据。
2. 字段名、字段别名和显示标题分开管理；SQL、程序和交换文件只使用真实字段名。
3. 坐标系、单位或 Z 方向没有证据时必须明确标记未知，禁止猜测。
4. 实测值、预测值和 NoData 分开表达；不得用数值 0 替代空值。
5. 每个数据集和模型成果必须有版本、来源、生成方法和输入哈希。

## 2. 数据分层

| 层级 | 类型标识 | 说明 | 是否可覆盖 |
|---|---|---|---|
| L0 | `raw_observation` | 论文配套 DOC、DAT、NODE、XLSX 等原始记录 | 否 |
| L1 | `standardized_observation` | 字段与数值类型统一、保留来源标识的观测数据 | 否 |
| L2 | `train_validation_split` | 可复现划分的训练集、验证集及划分摘要 | 否 |
| L3 | `model_result` | 插值预测、规则网格、体元、模型元数据和质量指标 | 仅允许新版本 |
| L4 | `visual_derivative` | 切片、截图、图例、布局、等值面和演示场景 | 允许重建，不得反写 L0—L3 |

建议标识格式：

```text
<data_type>_<method>_<resolution>_<parameter>_<version>
```

例如 `rho_kriging_20m_k40_v1`。SuperMap 数据集名称可以采用大写形式 `RHO_KRIG_FINAL_20M_40`，但必须在元数据中映射到稳定 `model_id`。

## 3. 公共登记字段

所有数据集至少包含以下元数据：

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `dataset_id` | string | 是 | 稳定唯一标识，不能使用易变绝对路径 |
| `dataset_type` | enum | 是 | 使用 L0—L4 对应类型标识 |
| `version` | string | 是 | 首版为 `0.1` 或业务版本 `v1` |
| `source_path` | string | 是 | Windows 绝对路径或相对项目路径 |
| `sha256` | string | 文件必填 | 64 位小写十六进制；SuperMap 内部数据集可使用导出清单哈希 |
| `row_count` | integer | 表格必填 | 不含表头，必须大于或等于 0 |
| `created_at` | datetime | 是 | ISO 8601，包含时区 |
| `created_by` | string | 是 | 人员、脚本或软件任务标识 |
| `source_reference` | string | 是 | 论文、原始文件或上游 `dataset_id` |
| `quality_status` | enum | 是 | `unreviewed/passed/warning/failed` |
| `notes` | string | 否 | 只写解释，不存放结构化参数 |

## 4. 地下电阻率标准数据契约

### 4.1 权威标准文件

下表路径相对于代码项目根目录，数据实际保存在相邻的只读资料目录 `../超图杯资料` 中。

| 数据集 | 相对路径 | 预期记录数 |
|---|---|---:|
| 标准化源数据 | `../超图杯资料/标准化数据/地下电阻率节点_标准化.csv` | 17,549 |
| 训练集 | `../超图杯资料/标准化数据/地下电阻率节点_训练集90.csv` | 15,827 |
| 验证集 | `../超图杯资料/标准化数据/地下电阻率节点_验证集10.csv` | 1,722 |

训练集与验证集按完整 `(X,Y)` 空间柱划分，空间柱交叉数必须为 0。划分种子为 `supermap-rho-block-cv-v1`。

### 4.2 CSV 结构

编码使用 UTF-8，分隔符为英文逗号，首行为字段名：

```csv
X,Y,Z,RHO
-40,340,-26.387,53.98255
```

| 字段 | 类型 | 必填 | 单位/方向 | 校验规则 |
|---|---|---:|---|---|
| `X` | float64 | 是 | 米；局部平面 X | 有限数值；同一文件中的坐标语义一致 |
| `Y` | float64 | 是 | 米；局部平面 Y | 有限数值；同一文件中的坐标语义一致 |
| `Z` | float64 | 是 | 米；当前文件使用负高程/向下为负 | 有限数值；不得在导入时再次取负 |
| `RHO` | float64 | 是 | 电阻率；原始资料单位需再次核对 | 有限且大于 0；不允许 `-9999` |

当前数据使用局部平面坐标，不附加未经证实的 EPSG。代码中使用：

```text
crs.type = local_engineering
crs.epsg = null
horizontal_unit = m
vertical_unit = m
z_positive = up
```

`RHO` 的物理单位在界面中暂显示为“电阻率（单位待来源确认）”；确认论文或原始数据说明后再更新契约版本。

### 4.3 CSV 校验顺序

1. 检查 UTF-8 和四个必填字段；
2. 检查每列均能解析为有限数值；
3. 检查记录数与登记值一致；
4. 检查 `RHO > 0`；
5. 检查重复 `(X,Y,Z)`；
6. 计算坐标和 RHO 范围；
7. 对训练/验证数据检查 `(X,Y)` 空间柱无交叉；
8. 生成校验报告，不修改输入文件。

## 5. 预测结果契约

### 5.1 验证点预测表

至少包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `point_id` | string | 验证点稳定标识；现有导出可暂用验证集行号映射 |
| `x`,`y`,`z` | float64 | 验证点三维坐标 |
| `rho_true` | float64 | 实测 RHO |
| `rho_pred` | float64/null | 预测值；导入 SuperMap 原始导出时 `-9999` 转为 null |
| `is_nodata` | boolean | `rho_pred` 是否无值 |
| `error` | float64/null | `rho_pred - rho_true` |
| `abs_error` | float64/null | `abs(error)` |
| `relative_error` | float64/null | `error / rho_true` |
| `depth_band` | string | 固定深度分段标识 |
| `column_id` | string | 格式如 `X-160_Y360` |
| `model_id` | string | 关联模型任务 |

规则：

- SuperMap 导出中的 `Attribute=-9999` 代表 NoData，只能在导入适配层识别；内部统一使用 null 加 `is_nodata=true`。
- 指标只能在 `is_nodata=false` 的公共有效点上计算。
- 当前五个模型的公共有效点为 1,481，公共 NoData 为 241，覆盖率约 86.0%。

### 5.2 三维规则节点交换表

外部算法与 SuperMap 之间使用：

```text
x,y,z,value,i,j,k,is_observed,is_valid,source_point_id,method,model_id
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `x`,`y`,`z` | float64 | 是 | 三维节点坐标 |
| `value` | float32/float64 | 是 | 属性值；单位由 `property_unit` 指定 |
| `i`,`j`,`k` | integer | 规则网格必填 | 从 0 开始的 X/Y/Z 网格索引 |
| `is_observed` | boolean | 是 | 是否直接来自实测约束 |
| `is_valid` | boolean | 是 | 是否通过质量检查 |
| `source_point_id` | string/null | 是 | 实测来源点；非实测节点可为空 |
| `method` | enum | 是 | `IDW/KRIGING_ORDINARY/GOCAD_DSI/PYTHON_DSI_LIKE` |
| `model_id` | string | 是 | 模型唯一标识 |

规则网格必须满足同一 `i,j,k` 组合唯一，坐标与原点、间距计算结果在浮点容差内一致。

## 6. 模型元数据契约

建议使用 JSON，至少包含：

```json
{
  "model_id": "rho_kriging_20m_k40_v1",
  "property": "RHO",
  "property_unit": null,
  "method": "KRIGING_ORDINARY",
  "input_dataset_id": "rho_standardized_v1",
  "input_sha256": "64-character-lowercase-hex",
  "crs": {"type": "local_engineering", "epsg": null},
  "axis": {"horizontal_unit": "m", "vertical_unit": "m", "z_positive": "up"},
  "grid": {"resolution_xy_m": 20, "rows": 7, "columns": 23, "bands": 42, "nodata": -9999},
  "parameters": {"search": "variable", "neighbor_count": 40, "slice_min_z_m": -840, "slice_interval_m": 20},
  "supermap": {"version": "iDesktopX 2026", "datasource_alias": "expore1", "dataset": "RHO_KRIG_FINAL_20M_40"},
  "status": "succeeded",
  "generated_at": "2026-07-18T00:00:00+08:00"
}
```

示例中的时间和哈希为结构示例，生成正式元数据时必须填写实际值，不得原样复制。

`status` 枚举：

- `created`：任务已登记；
- `running`：正在执行；
- `succeeded`：工具成功且输出通过最低完整性检查；
- `failed`：工具报错、对象为空或输出不可用；
- `invalidated`：历史结果因输入或规则变化不再作为正式成果。

## 7. 质量指标契约

| 指标 | 定义 | 方向 |
|---|---|---|
| MAE | `mean(abs(pred-truth))` | 越低越好 |
| RMSE | `sqrt(mean((pred-truth)^2))` | 越低越好 |
| R² | `1-SSE/SST` | 越高越好；分组样本小时谨慎解释 |
| Median AE | 绝对误差中位数 | 越低越好 |
| Mean ARE | `mean(abs(pred-truth)/truth)` | 越低越好 |
| log10 RMSE | 正值 truth/pred 的对数 RMSE | 越低越好 |
| Bias | `mean(pred-truth)` | 越接近 0 越好 |
| P90 AE | 绝对误差第 90 百分位 | 越低越好 |
| Coverage | 有效预测点数/全部验证点数 | 越高越好 |

比较多个模型时必须使用同一公共有效子集，并在结果中同时报告 `n_total`、`n_valid` 和 `n_nodata`。

## 8. 微震数据后续契约边界

微震正式标准化应拆为：

1. `survey_lines.csv`：测线、方向、局部原点和几何来源；
2. `survey_points.csv`：测点编号、所属测线、累计距离和局部 XY；
3. `velocity_samples.csv`：测点编号、源行号、深度字段原值、派生 Z、速度和质量标记。

当前约束：

- 研究主线为 L1、L2、L3；
- L3 标准测点为 W24—W27；
- W28 只保留为来源冲突和质量说明；
- 坐标为相对几何重建结果时，`crs.type=local_relative`；
- DAT 源字段 `WL/2(km)` 必须保留，论文派生深度另设字段，不能静默改名为 `Depth`。

## 9. 煤层瓦斯后续契约边界

当前标准化成果为 76 条样品和 29 组坐标。以下信息确认前只允许属性统计：

- “80系”的具体基准；
- 投影、中央经线、分带及带号；
- 两个坐标字段的轴顺序；
- 孔口高程；
- 采样止深的基准和正方向。

`BH001`—`BH029` 是标准化过程生成的坐标组 ID，不是原始孔号。候选修复值必须同时保留原始字段、质量标记和处理说明。

## 10. 版本与变更

数据契约发生以下变化时提升版本并使受影响模型进入 `invalidated` 审核：

- 坐标系、单位或 Z 方向改变；
- 字段含义或 NoData 规则改变；
- 原始数据重新清洗并改变记录集合；
- 训练/验证划分改变；
- 模型交换表的必填字段改变。

仅修正文档措辞而不改变数据语义时，可以更新修订号，不使模型失效。
