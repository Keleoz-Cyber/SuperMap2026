# GeoModelingPlatform v0.6 Professional Modeling Enhancements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one auditable professional spatial-analysis pipeline covering directional semivariograms, confirmed Kriging anisotropy, bounded search neighborhoods, fold inspection, two distinct uncertainty layers, connected anomaly extraction, and linked candidate comparison.

**Architecture:** Extend the v0.5 generic candidate identity rather than creating a second modeling system. Pure numerical modules produce deterministic artifacts; SQLite v5 and typed jobs own durable state; API, CLI, browser, and export all read the same manifests. Algorithm capabilities stay explicit: Kriging owns variograms, model anisotropy, and native standard deviation, while IDW and Kriging share neighborhood, fold, empirical-error, anomaly, and comparison services.

**Tech Stack:** Python 3.12, NumPy, SciPy, pandas, Pydantic v2, SQLAlchemy/SQLite, FastAPI, Typer, Vue 3, TypeScript, Element Plus, ECharts, Cesium compatibility components, pytest, Vitest, Playwright, GitHub Actions.

```python
@dataclass(frozen=True)
class PairSample:
    indices: np.ndarray
    total_pair_count: int
    used_pair_count: int
    sampled: bool
    sampling_rate: float
    seed: int
    distance_strata: np.ndarray

def seed_from_contract(data_sha256: str, canonical_config: bytes) -> int:
    digest = hashlib.sha256(data_sha256.encode("ascii") + b"\0" + canonical_config).digest()
    return int.from_bytes(digest[:8], "big", signed=False)
```

For `n*(n-1)/2 <= max_pairs`, return all `i<j`. Otherwise:

1. generate a deterministic oversample of pair ranks without replacement;
2. compute distances;
3. divide into fixed quantile distance strata;
4. allocate the cap across non-empty strata;
5. sort final `(i,j)` lexicographically.

Do not allocate an `n×n` distance matrix. Check cancellation every bounded
batch.
