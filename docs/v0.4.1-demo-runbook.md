# v0.4.1 答辩演示运行手册

> 适用版本：v0.4.1。目标：在一台已安装依赖的 Windows 答辩机上，用固定步骤稳定完成 5–7 分钟演示，并备好故障降级方案。本文不假设读者了解仓库结构。

## 1. 适用对象与范围

- 演讲者与现场操作手（可以是同一人）。
- 双路线：**路线 A**（通用上传建模现场闭环，主线）与 **路线 B**（内置电阻率 SuperMap 成果，技术链路与兜底）。
- 本手册只覆盖演示执行与故障恢复；建模契约细节见 `docs/v0.4-generic-modeling-loop.md`。

## 2. 三级检查清单

### 前一天

1. `python -m pytest -q` 与 `npm --prefix web run test:unit` 全绿；
2. `npm --prefix web run build` 已生成 `web/dist`；
3. `geomodeling demo-check --json` 无 `[BLOCKED]`（iServer 类 `[WARNING]` 可接受）；
4. 若计划展示路线 B：启动 iServer 并确认三个 WorkSpace 服务在线，电量充足、关闭自动更新与睡眠。

### 开机后（当天）

1. 执行 `scripts/start_demo.ps1 -CheckOnly -NoBrowser`，确认全部 `[PASSED]` 或仅 iServer 警告；
2. 清空浏览器无关标签页，预先打开一个干净窗口；
3. 如需路线 B，启动 iServer（约 100 秒），打开管理页确认服务。

### 上台前（5 分钟）

1. 用 `scripts/start_demo.ps1` 启动平台（或确认已复用健康实例）；
2. 打开 `http://127.0.0.1:8000/`，首页能看到「新建建模案例」与内置电阻率卡片；
3. 把「下载演示数据」先点一次，确认 CSV 可下载（哈希与仓库固定值一致由 demo-check 保证）；
4. 关闭无关弹窗与输入法悬浮窗。

## 3. 干净启动命令

```powershell
cd <仓库目录>
scripts/start_demo.ps1 -CheckOnly -NoBrowser   # 只检查不启动
scripts/start_demo.ps1                          # 检查 + 启动 + 打开浏览器
```

脚本使用独立数据目录 `var/demo_v041`，不安装依赖、不删除数据、不结束任何进程；端口上已是本平台健康实例时会提示复用。停止用 `Ctrl+C`。

## 4. 路线 A：通用建模现场闭环（5–7 分钟）

| 步骤 | 操作 | 讲解点 |
|---|---|---|
| 1 | 首页「新建建模案例」，命名 | 案例隔离、SQLite 持久化 |
| 2 | 上传 `demo/platform_demo_3d.csv` | 固定演示样例，SHA-256 防伪替换 |
| 3 | 字段映射：x/y/z/rho，局部线性坐标 | 语义映射、数值转换统计 |
| 4 | 展示质量门禁结果 | 阻断/警告语义、确认留痕 |
| 5 | 创建 IDW 实验（power=2、邻域 16）并运行 | 任务落库、可取消/重试 |
| 6 | （可选）再跑一组普通克里金 | 自动变异函数、折内拟合防泄漏 |
| 7 | 排行榜 | 空间折分、公共有效集合、覆盖率与排名的分离 |
| 8 | 打开最优候选成果 | 成果幂等物化 |
| 9 | 完整场点云 + X/Y/Z 三方向切片 | 真实坐标标签、NoData 透明 |
| 10 | 填写理由，登记正式模型 | 理由必填、历史可追 |
| 11 | 生成证据 ZIP 并下载 | 七文件、SHA-256 清单、失败候选证据 |
| 12 | 「返回实验」「返回首页」 | 无导航死路，任务后台继续 |

## 5. 路线 B：内置电阻率 SuperMap 成果（2–3 分钟）

- 首页进入「地下电阻率」只读案例：五模型排行榜与正式成果身份；
- 实测点云、S3M 体元格点与叠加切换、阈值/色带/Z 夸张；
- iServer 服务探测与六级发布证据链；
- 明确说明：体元为 SuperMap 体渲染采样（非逐格导出），S3M 解析器只保证兼容本机 iDesktopX 缓存格式。

## 6. 双路线切换规则

- 主线讲完路线 A 步骤 7（排行榜）后，可随时切路线 B 展示 SuperMap 链路；
- 路线 A 出现临时计算/浏览器问题时，立即切路线 B 兜底，并如实说明「路线 A 的通用流程已在前面的会话走通过，本节用已验证证据继续」。

## 7. 创新点与可见证据的对应

- 空间隔离验证 + 公共有效集合复算 → 排行榜页「公共有效点」字样；
- 失败候选不丢弃 → 排行榜失败行与错误码；
- 任务重启恢复 → 刷新页面后任务状态仍在（SQLite）；
- 体元缓存 fail-closed 解析 → 路线 B 体元格点与契约说明。

## 8. iServer 在线与离线讲法

- **iServer 在线**：「平台直接探测服务与数据集元数据，证据链六级逐层点亮，浏览器回执有严格身份校验。」
- **iServer 离线**：「通用建模全流程不依赖 iServer；内置案例的服务状态如实降级为未验证，但建模证据不丢失——这是平台的证据诚实性设计。」

## 9. 故障恢复表

| 场景 | 预期表现 | 现场处理 |
|---|---|---|
| iServer 离线 | 路线 A 全部可用；路线 B 服务状态为不可用/未知 | 继续路线 A；用备用截图讲发布链 |
| 浏览器刷新 | 案例/实验/任务由路由 ID 与 SQLite 恢复 | 重新进入原 URL 或从首页案例卡进入 |
| 任务失败 | 失败候选与错误码保留 | 不删除证据；修改参数或重试 |
| 任务运行中返回首页 | 后台继续运行 | 再次进入案例/实验查看 |
| 演示 CSV 被修改 | demo-check 哈希阻断 | 恢复仓库版本，不静默继续 |
| API 端口被占用 | demo-check 阻断并提示 | 换 `-Port` 参数；不结束未知进程 |
| 现场无法实时计算 | 不伪造实时成功 | 用备用截图与已导出 ZIP，声明是备用证据 |

## 10. 备用证据清单

- 当前实时验证截图：`docs/evidence/v0.9.0/`；旧 v0.4/v0.4.1 彩排可从对应 Git 标签恢复；
- 演示数据：`demo/platform_demo_3d.csv`（哈希固定）；
- 已导出的成果 ZIP：由最近一次彩排生成，仅存于本机运行时目录，不入库；
- 日志：启动窗口前台输出，结束后可复制保存。

## 11. 禁止宣称的边界

- 不做多源融合；电阻率、微震、瓦斯是独立案例，没有共同坐标依据时不叠加；
- 局部坐标没有已知 CRS/EPSG；不伪装成地理坐标；
- 瓦斯没有正式体元成果（iDesktopX 加载崩溃边界未解）；
- 微震派生流程**未代码化**，当前只是上传预设；不宣称已接入建模闭环；
- 浏览器 S3M 渲染是自研点元渲染，不是原生 GPU 体渲染；
- 通用成果发布当前为 manual_required，不宣称已自动发布到 iServer。

## 12. 演示后的收尾

- `Ctrl+C` 停止平台；iServer 用其 shutdown 脚本；
- 收集前台日志与必要截图，只把最终代表性证据纳入 `docs/evidence/v0.9.0/`，不要提交重复运行截图；
- 运行时数据目录 `var/demo_v041` 可保留供复盘，不入 Git。
