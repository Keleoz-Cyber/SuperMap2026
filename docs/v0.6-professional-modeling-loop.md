# v0.6 专业建模闭环运行手册（Windows）

> 适用分支：`feat/v0.6-professional-modeling`（发布候选，版本 0.6.0；v0.5.0 已发布，tag `v0.5.0`，merge `d37eb94`）。数据事实以 [data/contracts.md](data/contracts.md) 为准；设计口径以 `docs/superpowers/specs/2026-07-26-v0.6-professional-modeling-enhancements-design.md` 为准；本文只描述怎么跑。专业建模闭环不依赖 iServer。

## 1. 闭环含义与边界

v0.6 在 v0.4/v0.5 通用平台之上增加专业建模层：

```text
平台数据集（已通过质量门禁）
  → 专业诊断（全向 + 方向经验半变异函数，确定性点对采样）
  → 三模型加权有界最小二乘拟合证据 + 各向异性候选（诊断建议）
  → 人工确认（不可变快照，改参数必生成新快照）
  → 专业实验（IDW / 普通 Kriging，旋转邻域 + 扇区，整柱空间折分）
  → 专业分析台（折分检查 / 折外残差 / 两层不确定性 / 空间成果）
  → 显式阈值异常连通区（保存为不可变提取）
  → 双候选兼容比较（兼容才显示指标差）
  → 专业证据 ZIP 导出 → 发布登记 manual_required
```

必须保持的边界：

- 各向异性候选只是**诊断建议，需人工确认**；平台不自动采用候选，不自动宣称主方向。确认快照不可变：要改参数必须创建新快照，旧快照与其候选证据不被改写。
- 平台输出**两层、互相不可替代的不确定性**（§3.6）：Kriging 原生估计标准差与所有算法的经验误差尺度。二者都不是观测真值误差的概率保证。
- 异常区域只来自**显式阈值**、可选误差门槛和规则网格连通性；支持度量统一称「网格支持面积/体积估计」，不是地质储量，异常区不等于已验证的危险区。
- 局部工程坐标案例保持独立：没有共同控制点证据时不做跨案例空间叠加或融合。
- 发布登记保持 `manual_required`：iServer 发布是人工步骤，平台不自动发布。
- 旧候选（v0.5 及更早）没有专业工件：DTO 返回 `professional_capabilities.available=false`、`reason=LEGACY_RESULT_NOT_COMPUTED`，只读展示原有指标，不补算、不伪造零值或默认曲线。

## 2. 预检清单（Windows）

上台或演示前逐项确认：

1. Python 3.12+ 依赖已安装：`python -m pip install -e ".[api,test]"`（版本号以 pyproject 为单一来源，API 经 importlib-metadata 读取）。
2. 前端已构建：`npm --prefix web ci && npm --prefix web run build`（未构建时首页不可达，`demo-check` 会阻断）。
3. 通用预检通过：`geomodeling demo-check`（阻断项退出码 1；iServer/S3M/凭据缺失仅警告，专业建模流程不受影响）。
4. 数据目录可写：浏览器/API 使用 `GEOMODELING_DATA_DIR`（默认 `var/geomodeling`，被 Git 忽略）；CLI 用 `--data-dir` 显式指定同一布局。
5. 端口可用：默认 8000（或自选端口），被未知进程占用时 `demo-check` 阻断。
6. 目标数据集已通过质量门禁（`validated`）：专业诊断入口只在门禁通过后开放；SQLite 已迁移到 v5（比代码更新的数据库拒绝启动）。

## 3. 核心概念与精确口径

### 3.1 经验半变异函数与确定性点对采样

经典经验半变异函数：

```text
γ(h) = 1 / (2·N(h)) · Σ_(i,j)∈N(h) [Z(x_i) − Z(x_j)]²
```

每个 bin 返回距离下界/上界/中心、半变异值、点对数、实际平均距离、方向中心与容差、是否参与拟合及排除原因；低于 `min_pairs_per_bin` 的 bin 显示但不进入拟合；有效 bin 不足时诊断结构化失败，不静默退回旧版固定拟合。

点对采样是确定性的：

- 点对总数不超过上限（默认 `50,000`）时使用全部点对；超过时按距离层与方向层分层抽样；
- 随机种子来自数据 SHA-256 与诊断配置，不依赖进程时间；同一输入与配置必产生相同点对身份、曲线与哈希；
- DTO 与工件披露总点对、候选点对、实际点对、**采样率**与**种子**来源；只保存受限点对索引或分箱汇总，不提交私有原始点对。

### 3.2 方向约定

坐标轴遵守标准数据集的 X/Y/Z，不解释为经纬度：

- 方位角：XY 平面内从 +X 朝 +Y 旋转，范围 `[0°, 180°)`；
- 倾角：从水平面朝 +Z，范围 `[-90°, 90°]`；2D 数据不接受倾角参数；
- 方向无正反：向量 d 与 −d 属于同一方向；
- 角度容差显式保存；方向 bin 点对不足时标记 unsupported，不外推主方向。

### 3.3 理论模型拟合与参数来源

继续支持球状、指数、高斯三种模型；公共参数 `nugget ≥ 0`、`partial_sill > 0`、`sill = nugget + partial_sill`、`range > 0`。自动拟合使用按 bin 点对数加权的有界最小二乘，保存 `weighted_sse` 目标值、边界、收敛状态与残差；人工模式执行同样的有限性与范围校验。

参数来源（`parameter_origin`）必须区分，不得混报：

| 来源 | 含义 |
|---|---|
| `automatic_candidate` | 折内自动拟合候选：每一折只用该折训练数据拟合，只用于验证指标 |
| `final_full_data_fit` | 候选物化为完整场时在全部有效建模数据上重新拟合一次，只用于最终空间成果 |
| `manual_confirmed` | 人工确认的模型类型/方向/比例/参数策略；选择固定 nugget/sill/range 时标记 `user_prior`（用户先验，不是交叉验证自动拟合结果） |
| `legacy_auto_fold_fit` | v0.5 既有折内自动拟合（旧候选只读兼容） |

折内参数与全数据拟合参数在页面和导出中分别展示；数据集级诊断只用于建议和人工确认，不把全数据拟合注入折内验证造成泄漏。

### 3.4 各向异性候选与人工确认

平台从方向半变异函数的有效 range/结构差异生成候选（主方向、次方向与垂向支持度、range 比例、使用的方向 bin 与点对数、稳定性警告）。候选只是**诊断建议**：用户必须显式确认或选择「保持各向同性」。确认记录保存方位角、3D 倾角、绕主轴滚转角、主/次/垂向尺度比、证据引用、确认说明与时间，写入**不可变**快照。

确认后的变换只属于普通 Kriging。定义物理坐标向量 x、旋转矩阵 R、尺度矩阵 `S = diag(1/a_major, 1/a_minor, 1/a_vertical)`：

```text
x′ = S Rᵀ x
```

Kriging 的经验半变异函数距离、协方差距离与经验误差距离使用同一个变换指纹；专业 Kriging 不再叠加第二个不透明的 `z_scale`，旧 `z_scale` 被规范化为尺度矩阵的一部分。兼容口径：旧候选继续按原 `z_scale` 读取；`z_scale=1`、比例全 1、旋转为 0 时等价于旧各向同性距离；成果网格物理 X/Y/Z 永远不变。IDW 不获得 Kriging 各向异性能力，其权重仍用 `(x, y, z × z_scale)` 距离。

### 3.5 旋转搜索邻域与扇区

2D 参数为主半径、次半径、方位角；3D 增加垂向半径、倾角与滚转角；另有 `min_neighbors`、`max_neighbors`、`sector_count`、`max_per_sector` 与精确同点策略。选择顺序：安全外接半径有界查询 → 邻域旋转坐标内椭圆/椭球判定 → 分配扇区 → 扇区内按距离稳定排序截断（次键为标准数据 `source_row`）→ 合并限制 `max_neighbors`；少于 `min_neighbors` 返回 NoData 与原因。不自动扩大半径、不减少 `min_neighbors`、不退化全局搜索。

IDW 与普通 Kriging 共用同一邻域选择器；Kriging 邻域方向默认与已确认的模型各向异性联动；IDW 的邻域方向只属于采样几何，不改变其 `z_scale` 权重距离，也不得标记为「IDW 变异函数各向异性」。

### 3.6 两层不确定性（命名纪律）

平台同时提供两层不确定性，含义不同、不得互相冒充：

1. **Kriging 原生估计标准差**（仅普通 Kriging）：Kriging 线性系统在返回权重 λ 的同时返回拉格朗日乘子 μ，基于半变异函数形式的原生方差

   ```text
   σ² = λᵀγ₀ + μ
   ```

   单位为值单位平方，页面默认显示标准差。仅浮点容差内的微小负值钳制为 0 并计入诊断；显著负值、非有限值或奇异解返回该目标 NoData 与原因；使用最小二乘降级时必须在方差工件中标记。它是模型原生的估计标准差，不是观测真值误差的概率保证，不得描述成概率区间或未来事件风险。

2. **经验误差尺度**（所有算法，IDW 与 Kriging 同口径）：使用折外残差点，在同一专业空间变换与显式误差邻域内选取附近残差，计算**距离加权局部 RMSE**，并同时返回局部残差数量与有效覆盖率；邻点不足返回 NoData。它**不是标准误**，也不是任何概率意义的不确定区间，不能用全局 RMSE 常数填满空间场冒充局部不确定性。

### 3.7 能力矩阵

| 能力 | IDW | 普通 Kriging |
|---|---|---|
| 全向/方向半变异函数 | `not_applicable` | 支持 |
| 模型各向异性 | `not_applicable` | 支持，人工确认 |
| `z_scale` 权重距离 | 支持 | 旧候选兼容；新候选归一化到空间变换 |
| 旋转椭圆/椭球搜索邻域 | 支持 | 支持 |
| 扇区邻点限制 | 支持 | 支持 |
| 空间折分检查 | 支持 | 支持 |
| 折外残差与经验误差尺度 | 支持 | 支持 |
| Kriging 原生标准差 | `not_applicable` | 支持 |
| 显式阈值异常连通区 | 支持 | 支持 |
| 双候选兼容比较 | 支持 | 支持 |

「不适用」是类型化 capability 状态（`not_applicable`），不得以空数组、0 或失败状态表达；IDW 不生成 `kriging_standard_deviation.npz`，manifest 用 capability 明确说明，不用空文件占位。旧候选返回 `LEGACY_RESULT_NOT_COMPUTED`，见 §1。

### 3.8 异常区域

每次提取必须明确：`direction = high | low`、值阈值（高值 `value >= threshold`，低值 `value <= threshold`）、可选经验误差尺度上限、Kriging 可选原生标准差上限、最小支持节点数、连通规则版本。NoData 与不满足不确定性门槛的节点不进入掩膜。

连通规则保守固定：2D 使用 **4 邻接**、3D 使用 **6 邻接**，不用对角接触合并；空间间隔不规则的网格阻断。每个连通区返回 component ID、支持节点数、面积/体积支持估计、包围盒、几何中心、值 min/max/mean、误差摘要与是否接触网格边界。面积/体积按规则网格节点的 **Voronoi** 支持区计算（内部边界取相邻轴坐标中点，最外边界裁剪到网格 bounds），统一称「**网格支持面积/体积估计**」，不是地质储量。预览可调参数；只有点击保存后才创建不可变 `AnomalyExtraction` 并进入正式导出证据。

### 3.9 比较兼容指纹

两个候选同时满足同一 `dataset_version_id`、同一验证折分指纹、同一验证目标行身份、同一公共有效掩膜定义与一致值单位时，比较结论为 `compatible`，显示同口径指标差、残差差、场差与异常区差异；否则为 `incompatible`，只允许左右独立查看并解释不兼容字段，禁止显示 RMSE/R²/覆盖率差值。兼容性由后端判定，前端不自行判断；场差只在相同网格定义与共同有效节点上计算。

## 4. 浏览器路线

```powershell
python -m uvicorn geomodeling.api.app:app --host 127.0.0.1 --port 8000 --workers 1
# 浏览器打开 http://127.0.0.1:8000/
```

1. **专业诊断**：案例内打开已通过质量门禁的数据集，点「专业诊断」进入诊断工作台；配置方向数、lag、上限等参数后「开始专业诊断」。页面展示全向/方向经验半变异函数（每 bin 显示点对数）、三模型拟合证据与各向异性候选（标记「诊断建议，需人工确认」）。
2. **人工确认**：在诊断工作台确认各向异性参数或选择「保持各向同性」，填写确认说明，生成不可变确认快照。
3. **专业实验**：在调参实验室为 IDW / 普通 Kriging 候选选择确认快照与旋转邻域参数并运行；空间折分泄漏检查不通过时整次运行失败。
4. **专业分析台**：成果页点「专业分析」进入专业分析台，同一候选身份联动七个面板——结构诊断、参数快照（含参数来源）、折分检查（逐折训练/验证切换、泄漏证据、折外残差点）、误差与不确定性（残差分布、经验误差尺度、Kriging 标准差，颜色表与预测值分开）、空间成果（完整场与 X/Y/Z 切片）、异常区域、证据与导出。
5. **异常提取**：在异常区域面板调整阈值与门槛预览连通区，确认后保存为不可变提取。
6. **双候选比较**：固定选择两个候选；后端返回兼容结论，兼容时显示同口径差值，不兼容时只左右独立查看。
7. **导出**：成果导出 ZIP 增加 `professional/` 证据目录（§6）；发布登记仍为 `manual_required`。

## 5. CLI 路线

CLI 与 API 共用服务层，`--data-dir` 必需，JSON 输出使用逻辑身份与相对工件名（无绝对路径）：

```powershell
geomodeling professional diagnose --data-dir var/geomodeling --dataset-id <数据版本id> --config-json '{}'
geomodeling professional confirm --data-dir var/geomodeling --diagnosis-id <诊断id> --note "确认说明" --config-json '{}'
geomodeling professional inspect-result --data-dir var/geomodeling --result-id <候选成果id>
geomodeling professional extract-anomalies --data-dir var/geomodeling --result-id <候选成果id> --config-json '{"direction":"high","threshold":1.0}'
geomodeling professional compare --data-dir var/geomodeling --first <候选A> --second <候选B>
```

`diagnose` 与 `extract-anomalies` 同步执行到终态：状态非 `succeeded` 时退出码 1 且 DTO 含统一错误码；`confirm` 输出不可变快照指纹；`compare` 输出 `compatible`/`mismatches`/`metric_deltas` 与比较指纹。

## 6. API 一览

```text
POST /api/datasets/{dataset_id}/professional-diagnostics      # 202 + 任务身份；同指纹成功幂等 200
GET  /api/professional-diagnostics/{diagnosis_id}             # 状态/指纹/manifest 摘要
GET  /api/professional-diagnostics/{diagnosis_id}/variogram   # 全向+方向曲线证据
POST /api/professional-diagnostics/{diagnosis_id}/confirm     # 201，不可变确认快照
GET  /api/analysis-jobs/{job_id}                              # 专业分析任务状态
POST /api/analysis-jobs/{job_id}/cancel                       # 取消当前任务，不改已有成功工件
POST /api/analysis-jobs/{job_id}/retry                        # 201，新任务并记录 retry_of
GET  /api/results/{result_id}/professional                    # 能力/参数来源/manifest 摘要
GET  /api/results/{result_id}/folds                           # 折分计划、泄漏检查、逐折指标
GET  /api/results/{result_id}/residuals                       # 折外残差（有界预览）
GET  /api/results/{result_id}/uncertainty/{kind}              # kind=empirical_error|kriging_std，有界抽稀预览
POST /api/results/{result_id}/anomaly-extractions             # 202 + 任务身份；同配置成功幂等 200
GET  /api/anomaly-extractions/{extraction_id}                 # 状态/配置/components 预览
POST /api/professional-comparisons                            # 201，比较两个成功候选
GET  /api/professional-comparisons/{comparison_fingerprint}   # 按比较指纹幂等查询
GET  /api/professional-artifacts/{kind}:{subject}:{logical}/download  # 白名单工件下载
```

要求：每条链验证 case → dataset → experiment → run → result 所有权；结果与诊断不属于同一数据版本返回 409；工件下载只走服务端白名单映射，不接受路径；大数组抽稀/分页/有界二进制；公共 DTO 不暴露绝对路径、SQLite 内容或私有源文件名；长任务返回 202 与任务身份，诊断与异常提取使用 `analysis_jobs` 持久化任务，不在请求中执行长计算；所有错误使用统一错误封套。

## 8. 失败与降级语义表

| 情况 | 行为 |
|---|---|
| 有效点或点对不足、有效 bin 不足 | 诊断结构化失败（统一错误码，CLI 退出码 1） |
| 方向 bin 支持不足 | 标记 unsupported，不外推主方向；不得静默改全向后声称方向模型成功 |
| 自动拟合不收敛或参数到达非法边界 | 拟合失败并保存收敛/边界证据 |
| 各向异性矩阵非有限、不可逆或比例非法 | 确认失败，不写入快照 |
| 邻域参数矛盾（半径非正、min>max、扇区容量不足） | 请求被拒绝 |
| 某目标邻点不足 | 该目标 NoData + 原因；不自动扩半径、不退化全局最近 K 点 |
| Kriging 方差显著为负或非有限 | 该目标 NoData + 原因；微小负值钳制计入诊断；lstsq 降级在工件中标记；不得用经验误差尺度冒充 |
| 经验误差尺度邻点不足 | NoData；不得用全局 RMSE 常数填充 |
| 空间折分泄漏 | 泄漏检查非通过即整次运行失败（fail-closed），不只显示警告 |
| 折外残差覆盖不足 | 结构化失败 |
| 请求不适用算法的 capability | 类型化 `not_applicable`，不以空值或失败冒充 |
| 异常提取请求了不存在的不确定性层 | 失败，不忽略门槛 |
| 网格不规则 | 异常提取阻断 |
| 工件缺失或哈希不符 | 导出 409 fail-closed |
| 候选比较指纹不兼容 | `incompatible`，不显示指标差 |
| 进程重启 | 在途 `analysis_jobs` 转 `interrupted`，不重排队；重试创建新任务并记录 `retry_of` |
| 取消 | 只影响当前任务，不删除已有成功诊断、候选或成果 |

同一资源最多一个同类在途任务（部分唯一在途索引）；状态写入数据库后才上报成功，不允许内存后台线程立即返回「成功」。

## 9. 已知边界与禁止表述

明确不做（设计 §3.2）：普适 Kriging、协同 Kriging、指示 Kriging；稳健半变异函数估计器或超过三种的理论模型库；自动采用各向异性候选；Bootstrap、贝叶斯后验或概率区间；时间预测、微震事件预报或灾害预警；新位置上传预测的独立业务流程；任意斜切面；DSI-like/GOCAD 后端；瓦斯正式案例；跨案例空间融合；iServer 自动发布；首页、导航和全站视觉体系重做。「预测」在 v0.6 仅表示现有空间插值对规则网格或验证点的估计。

允许表述（设计 §21）：

- 「平台提供方向半变异函数诊断，并由用户确认各向异性参数。」
- 「普通 Kriging 同时输出空间估计和模型原生估计标准差。」
- 「所有算法基于折外残差展示经验误差尺度。」
- 「异常区域来自显式阈值、误差门槛和规则网格连通性。」
- 「参数、验证指标、不确定性和空间结果通过同一候选身份联动。」

禁止表述（设计 §21，以下仅为引述对照，禁止作为能力宣称；文档扫描只放行本 fixture 区）：
