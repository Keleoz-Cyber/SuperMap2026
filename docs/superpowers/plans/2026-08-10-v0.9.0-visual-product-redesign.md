# v0.9.0 Visual Product Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the full browser product into an answer-stage “deep-earth aurora” command center with a first-class custom-data path, explainable tuning, integrated 3D analysis, evidence-backed findings, and a controlled presentation mode.

**Architecture:** Keep the v0.8.1 FastAPI contracts, model identities, routes, and NetCDF/SuperMap rendering chain intact. Add a Vue product shell, deterministic presentation selectors over existing DTOs, reusable evidence and state components, and progressively migrate each existing view into the shared shell. Treat real browser output with repository-frozen cases as the release gate; unit and mock tests protect contracts but do not substitute for visual acceptance.

**Tech Stack:** Python 3.12, FastAPI/Pydantic/SQLAlchemy, Vue 3, TypeScript, Vite, Element Plus, ECharts 5, SuperMap3D/iClient3D iframe protocol v2, Vitest, Playwright, pytest.

## 2. Stable front-end contracts

Define these types once; later tasks must import them rather than create page-local variants.

```ts
// web/src/domain/findings.ts
import type { AnalysisSummaryResponse } from '../api/types'

export type FindingConfidence = 'verified' | 'exploratory' | 'insufficient' | 'unavailable'

export interface FindingSpatialTarget {
  axis: 'xy' | 'x' | 'y' | 'z'
  xRange?: [number, number]
  yRange?: [number, number]
  range?: [number, number]
  resultId?: string
}

export interface PresentationFinding {
  id: string
  title: string
  statement: string
  evidence: string[]
  source: {
    datasetId: string
    sourceSha256: string
    calculationVersion: string
  }
  confidence: FindingConfidence
  limitations: string[]
  spatialTarget?: FindingSpatialTarget
}

export type FindingBuilder = (
  summary: AnalysisSummaryResponse,
) => PresentationFinding[]
```

function qualityFinding(summary: AnalysisSummaryResponse): PresentationFinding

Rules:

- Quality statement is `有效数据 {valid}/{rows}（{ratio}%）`; `verified` only when counts are finite and consistent.

- Profile finding uses only modules with `status === 'ok'` and finite payload values.
- Every finding copies dataset ID, source SHA-256, calculation version, and at least one limitation.
- Missing/malformed modules produce no finding, not zero-valued fake evidence.
