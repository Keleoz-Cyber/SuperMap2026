# v0.9.0 机器学习空间预测设计

## 1. 目标

在现有地质三维建模平台中增加一条可审计、可比较、可渲染的机器学习空间预测链。第一版不是独立“AI 中心”，而是把机器学习作为现有建模实验的一类候选方法，完整复用数据版本、空间验证、候选排行、成果物化、NetCDF、三维渲染、切片、剖面、导出和成果分析。

交付两种算法：

- `random_forest_spatial`：随机森林空间回归；
- `kriging_rf_residual`：普通克里金基线 + 随机森林折外残差校正。

系统必须允许机器学习输给普通克里金，并用同一公共有效集如实展示结果。不得以“AI”名义改变排名口径或隐藏较差指标。

## 2. 产品位置

### 2.1 新建实验

算法区分为两组：

- 传统空间建模：IDW、普通克里金、DSI-like；
- 机器学习预测：随机森林空间预测、克里金残差校正。

机器学习卡片显示适用条件、预计计算量和主要产出。高级参数折叠展示，默认值可直接运行。瓦斯 58 点数据不默认开放复杂机器学习；用户可进入“实验性评估”，但提交前必须确认小样本限制。

### 2.2 模型比较

机器学习候选与现有候选使用相同的 RMSE、MAE、R²、Bias、覆盖率、验证方法、折分指纹和公共有效集合同。比较页增加“相对普通克里金变化”，只在同数据版本、同验证指纹且存在克里金对照时计算。

### 2.3 分析中心与成果空间

分析中心增加“机器学习适用性”摘要，说明样本量、空间组数量、验证方式、模型是否具有稳定提升及主要限制。

成果空间不新增平行页面，在现有三维工作台中提供场变量切换：

- 预测值；
- 模型离散度参考；
- 克里金基线（仅残差校正）；
- 校正量（仅残差校正）。

右侧分析区展示基线与校正后指标、校正量分布、离散度高值区域和结论。所有结论使用“预测”“参考”“提示”等措辞，不输出安全/危险或确定性地质判断。

## 3. 算法合同

### 3.1 空间特征

特征变换只使用坐标，不读取验证目标值或全数据统计。每次 `fit` 仅基于训练坐标计算中心与尺度，并对训练点和查询点使用同一变换。

三维默认特征：

- 标准化 `x/y/z`；
- 到训练域中心的标准化径向距离；
- `xy/xz/yz` 二阶交互项；
- `x²/y²/z²`。

二维省略 z 相关项。尺度为零时按 1 处理，输出必须全有限且列顺序稳定。特征版本固定为 `spatial_features.v1` 并进入候选参数与证据。

### 3.2 随机森林空间预测

使用 `scikit-learn` 的 `RandomForestRegressor`，固定 `n_jobs=1` 以保证跨环境可控，随机种子显式进入参数和候选指纹。

第一版参数边界：

| 参数 | 默认 | 范围 |
|---|---:|---:|
| `n_estimators` | 160 | 40–400 |
| `max_depth` | 18 | 4–40 或 null |
| `min_samples_leaf` | 2 | 1–20 |
| `max_features` | 0.8 | 0.3–1.0 |
| `random_state` | 20260813 | 固定整数 |

预测值为各树预测均值；“模型离散度参考”为各树预测标准差。该离散度不是严格概率置信区间，API 和界面必须披露此限制。

### 3.3 克里金残差校正

外层空间验证的每一折中，训练流程如下：

1. 仅使用该外层折训练集建立确定性的 3 折内层空间分组；
2. 在内层每一折上拟合普通克里金并预测内层验证点；
3. 计算 `observed - kriging_oof_prediction`，只保留有限的折外残差；
4. 用这些折外残差训练随机森林残差模型；
5. 用全部外层训练点拟合最终普通克里金基线；
6. 对外层验证点输出 `kriging_baseline + predicted_residual`。

禁止用同一批训练点的拟合内预测残差训练随机森林。内层折分不足、克里金覆盖不足或有效残差少于门槛时，候选类型化失败，不回退成普通克里金并冒充校正成功。

最终物化在全部有效数据上重复相同逻辑：内层 OOF 残差训练 RF，全部数据拟合最终克里金。辅助场包括基线预测、校正量和残差森林树间离散度。

## 4. 小样本与适用性门

按有效样本和独立 XY 空间组数量判定：

- `supported`：有效样本不少于 200，空间组不少于 30；
- `experimental`：有效样本 80–199 或空间组 15–29；
- `not_recommended`：有效样本少于 80 或空间组少于 15。

`random_forest_spatial` 在 experimental 状态允许用户确认后运行；`kriging_rf_residual` 需要 supported。瓦斯预置数据为 58 点，默认 `not_recommended`，不提供无提示的一键运行。该门是产品与科学口径，不把样本数包装成绝对统计定律；具体计数和原因必须返回前端。

## 5. 运行、证据与比较

两种算法继续进入 `Experiment → Run → CandidateResult`。现有 runner 的外层空间折、公共有效集、OOF 预测、折分指纹和候选指标保持权威。

每个 ML 候选额外记录：

- 特征版本与列名；
- sklearn 版本；
- 随机种子与参数；
- 训练样本数、空间组数；
- 残差算法的内层折分指纹、有效 OOF 残差数和基线覆盖率；
- 树间离散度摘要；
- 是否触发小样本限制。

候选指纹包含算法、全部参数、外层验证合同、网格和特征版本。相同环境、输入和参数必须得到稳定预测；浮点结果采用既有数值容差，不承诺跨 BLAS/不同 sklearn 版本字节级完全一致。

## 6. 成果与渲染资产

主预测场继续写入 `grid.npz` 和 `metadata.json`。ML 辅助场写入同一结果目录的 `ml_fields.npz`，包含共享 axes 身份与逐场 NoData：

- `model_dispersion`；
- `kriging_baseline`（残差算法）；
- `residual_correction`（残差算法）。

`ml_fields.json` 保存每个场的语义、单位、值域、SHA-256、限制说明和主网格 SHA。写入使用同级临时文件、回读形状/有限性校验与原子替换；任一辅助场失败则整个 ML 物化失败，不留下“主场成功、辅助场丢失”的半成品。

渲染资产 API 增加可选 `field`，默认 `prediction`，其余值只接受 manifest 中登记的 ML 场。每个 field 生成独立、内容寻址的 NetCDF 渲染资产，不覆盖主预测资产。切片、剖面和导出均携带 field 身份。

## 7. API 与错误语义

新增只读能力接口：

`GET /api/datasets/{dataset_id}/ml-capability`

返回支持等级、样本数、空间组数、可用算法和用户说明。

实验创建沿用现有接口，仅扩展算法枚举与参数 schema。主要错误码：

- `ML_DATASET_TOO_SMALL`；
- `ML_SPATIAL_GROUPS_INSUFFICIENT`；
- `ML_EXPERIMENTAL_CONFIRMATION_REQUIRED`；
- `ML_INNER_SPLIT_FAILED`；
- `ML_RESIDUAL_COVERAGE_INSUFFICIENT`；
- `ML_ARTIFACT_INVALID`；
- `ML_FIELD_NOT_AVAILABLE`。

错误响应不包含本机路径、训练数据内容或 Python 堆栈。

## 8. 前端视觉与交互

机器学习算法选择采用与现有实验室一致的紧凑卡片，不另造营销页。卡片用简短结构表达“适合什么、输出什么、限制什么”。能力门返回后，禁用项显示具体原因。

成果空间的变量切换使用分段控件，放在三维控制区首层；切换后标题、单位、色带、切片和右侧证据同步更新。预测值使用案例原单位；校正量沿用原单位并使用以 0 为中心的发散色带；离散度使用非负顺序色带。

桌面主验收尺寸为 1920×1080 和 1440×900；390×844 只保留摘要、变量切换和主要操作，不把桌面三栏机械堆叠。加载、失败、辅助场不可用和切换中均有稳定占位，避免黑屏或布局跳动。

## 9. 测试与真实验收

后端测试覆盖：

- 特征训练域隔离与确定性；
- RF 参数边界、固定种子、均值/离散度；
- 残差模型确实使用内层 OOF 残差；
- 外层验证点从未进入任何训练层；
- 小样本门与瓦斯限制；
- 公共有效集比较；
- ML 多场原子物化、哈希、损坏 fail-closed；
- field 渲染资产、切片、剖面、导出身份。

前端测试覆盖能力状态、算法分组、实验性确认、指标比较、变量切换、通俗错误和响应式布局。Mock E2E 覆盖完整实验闭环。

真实数据验收至少覆盖电阻率和微震各一组 RF 候选；残差校正至少完成一组真实数据验证。真实 SDK/GPU 必须截图验证预测、离散度和校正量三种场的 Volume 与一个 Slice，且有像素内容门、控制台错误门、缓存刷新门和身份 JSON。瓦斯只验收限制提示，不伪造 ML 成果。

## 10. 明确不做

- 不做 3D CNN、U-Net、LSTM、Transformer 或大模型数值预测；
- 不做跨案例联合训练；
- 不做自动危险等级、储量或灾害结论；
- 不做无限制超参数搜索；
- 不把随机拆分指标作为主指标；
- 不把树间标准差称为严格置信区间；
- 不保证机器学习优于普通克里金；
- 不在功能完整和独立复审前合并到 `main`、打标签或创建 Release。
