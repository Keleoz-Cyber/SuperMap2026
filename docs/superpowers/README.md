# superpowers 过程档案

本目录是 v0.9.x 末期最后一轮功能开发的**过程档案**（实施计划 plans/ 与设计快照 specs/，一一对应），只增不改；与当前事实冲突时以权威文档（[../README.md](../README.md) 索引）为准。

阅读注记：

- 计划中的 checkbox 是当时的工作快照，未勾选不代表功能未落地；
- 各 spec 中的产品版本号停留在写作当日（0.9.x），当前版本以 [../../CHANGELOG.md](../../CHANGELOG.md) 为准；
- `2026-08-14-geological-interpretation-workbench`（研判工作台，先落地）与 `2026-08-14-plain-language-analysis-copy`（文案口语化，后落地）是同日先后迭代关系：前者建立"事实/可能解释/潜在影响/建议核查"固定栏目，后者按新要求移除固定栏目名改为自然叙述--并排阅读时以后者为准。
