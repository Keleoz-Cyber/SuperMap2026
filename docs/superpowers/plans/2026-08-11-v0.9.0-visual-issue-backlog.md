# v0.9.0 Visual Issue Backlog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复统一问题清单中的阻断缺陷和全站视觉不一致，使主要业务路由成为一套可读、可操作、可验证的比赛展示系统。

**Architecture:** 保留现有 Vue 3、Element Plus、ECharts 和 SuperMap3D 数据合同，只统一展示层与交互状态。三维组件以完整 `components_preview.rows` 为事实源；图表共享可读格式化合同；所有页面进入单一 `AppShell/AppHeader/PageContextHeader`；案例阶段由 URL 查询参数驱动真实条件渲染。

**Tech Stack:** Vue 3、TypeScript、Vitest、Vue Test Utils、ECharts、Playwright、SuperMap3D。
