# GeoModelingPlatform 产品蓝图

## 1. 产品定位

GeoModelingPlatform 不是单一插值脚本，也不是只展示预制模型的三维网页。它的最终形态是“上传数据后完成校验、调参建模、空间验证、成果分析和三维展示”的浏览器平台。

核心价值：把地质属性建模中分散的数据处理、算法试验、证据检查和 SuperMap 三维表达收敛到同一条可追溯流程。

## 2. 面向用户

- 地质/GIS 学生：不写代码也能完成标准建模流程。
- 专业人员：能检查变异函数、空间折分、邻域、误差和异常区。
- 评委：能快速看到问题、方法、结果、可信度和创新点。
- 开发维护者：能通过统一数据合同、任务状态和测试复现实验。

## 3. 主流程

以下流程均已实现，未来工作集中在比赛交付、彩排和新增数据接入，不再另造一套产品主链。

v0.6 专业建模增强已经进入当前实现；方向半变异函数、各向异性、专业邻域、经验误差和异常区不是未来占位功能。

```text
选择案例或上传数据
  → 字段映射与质量门禁
  → 选择算法和参数
  → 空间交叉验证
  → 候选比较与适用性判断
  → 正式成果选择和物化
  → 三维体/等值面/正交切片
  → 统计、规则、AI 与证据导出
```

任何阶段失败都必须显示原因；不能用空图、假按钮或降级点云冒充正式三维成果。

## 4. 功能分区

| 分区 | 职责 |
|---|---|
| 首页 | 展示三类案例、关键发现、当前成果和稳定主导航 |
| 案例工作台 | 管理数据、实验、比较和成果四阶段 |
| 数据接入 | 上传、映射、预览、质量检查和来源登记 |
| 调参实验室 | IDW、克里金、DSI-like 和机器学习参数配置 |
| 空间结构分析 | 半变异函数、方向性、各向异性和邻域诊断 |
| 模型比较 | 公共有效集指标、严格排名、差异和行动建议 |
| 成果工作台 | 三维渲染、切片、异常、规则、AI、模型证据与溯源 |
| 导出与发布 | 正式成果、证据 ZIP、报告和发布状态登记 |

## 5. 算法层

### 5.1 基础插值

- IDW：适合建立快速基线和参数敏感性对照。
- 普通克里金：使用经验半变异函数和可验证的模型参数。
- DSI-like：工程化离散平滑近似，用于方法对比，不宣称等同 GOCAD DSI。

### 5.2 机器学习空间预测

- 随机森林空间回归：以坐标派生特征学习非线性趋势。
- 克里金残差随机森林：以普通克里金为基线，用折外残差学习剩余结构。

机器学习必须经过数据适用性门：有效样本、独立空间组、折分可行性和公共有效集。没有提升时明确显示“未优于普通克里金”。

### 5.3 专业证据

- 方向/全向经验半变异函数；
- 球状、指数和高斯模型拟合；
- 人工确认的各向异性快照；
- 旋转邻域和扇区搜索；
- 克里金估计标准差与折外经验误差；
- 2D/3D 异常连通区。

## 6. 三维表达

- 统一使用 RenderAsset 描述可渲染成果。
- 规则网格导出为 NetCDF，交给 SuperMap3D `VoxelGridLayer3D`。
- 支持 Volume、Contour 和 X/Y/Z Slice。
- 三维场、切片热力图、统计和异常区共享成果身份及筛选上下文。
- 渲染失败时显示诊断，不回退成可能误导的伪成果。

## 7. 数据和证据原则

- 原始数据只读；所有派生步骤带规则版本和来源哈希。
- NoData 与无效值不能偷偷改成 0。
- 空间验证必须按 XY 柱/空间组折分，防止同一空间柱泄漏。
- 候选比较必须基于公共有效集。
- 选择、物化、导出和发布均记录成果身份。
- 公开 DTO、日志和导出包不得出现本机绝对路径或凭据。

## 8. 三个案例的产品角色

- 电阻率：完整主案例，展示算法广度、机器学习和成熟三维成果。
- 微震：第二专业案例，展示领域派生、异常清洗、稀疏空间组与实验性预测。
- 瓦斯：稀疏样本反例，展示适用性门、负 R² 如实披露和“不应使用机器学习”的系统判断。

三者使用独立局部坐标，产品层统一流程，但不伪造统一地理空间。

## 9. 创新点

1. 数据—算法—验证—三维—证据的纵向闭环，而非单点工具拼接。
2. 基于空间折分和公共有效集的公平候选比较。
3. 克里金与机器学习残差校正的统一工作流，并显式防止验证泄漏。
4. 算法适用性门：系统不仅“能运行”，还会拒绝不适合的数据和模型。
5. SuperMap 三维与权威切片/统计联动。
6. 来源哈希、不可变快照、导出清单和发布状态组成的证据链。
7. DSI-like、离散度、局部坐标和 AI 解释均带清晰边界，避免过度宣称。

## 10. 答辩主线

推荐使用电阻率案例完成 6–8 分钟主演示：

1. 首页说明问题与三案例定位；
2. 进入电阻率案例，查看数据质量；
3. 创建 IDW/克里金/机器学习实验；
4. 展示空间交叉验证和候选差异；
5. 选择成果，在同一三维场切换预测、基线、残差和离散度；
6. 打开切片和异常分析；
7. 展示证据链和导出；
8. 用微震和瓦斯说明平台可迁移性及适用性门。

## 11. 验收目标

- 新数据能够走通上传、门禁、实验、比较、成果和导出。
- 同一输入和参数得到确定性结果。
- 页面无导航死路、无伪按钮、无关键错误码直接暴露给普通用户。
- 1920×1080 答辩视口中核心工作台可用；手机端无横向溢出。
- iServer 离线时主建模链可运行且状态如实降级。
- 所有正式结论都能定位到数据、参数、指标和证据。

具体验收命令见[验收标准](acceptance.md)，当前实现状态见[当前状态](status/current-status.md)。
