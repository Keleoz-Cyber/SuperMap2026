# 统计与空间分析本机证据落点

该目录只定义 `analysis-center-live.spec.ts` 的本机真实运行输出位置，不保留历史重复截图。

测试以 `example_data` 为源，运行 `seed-resistivity` 和 `seed-microseismic`；生成目录使用 `run_id`，身份文件登记 40 位 `git_commit`。`run-*` 默认被 Git 忽略。任何准备入库的证据必须能核对数据/成果身份、提交祖先、控制台、网络和交互结果。当前正式答辩证据见 `docs/evidence/v0.9.0/` 与 `docs/evidence/v0.9.0-result-analysis-live/`。
