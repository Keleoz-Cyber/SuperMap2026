# ADR-0004 SQLite 单库加不可变文件工件

- 状态：已接受
- 日期：2026-07-25（v0.4.0 起），2026-08-15 补记

## 背景

平台必须在离线单机环境零依赖运行；同时存在大量二进制工件（标准化 Parquet、预测 Parquet、网格 npz、NetCDF、证据 ZIP）与结构化状态（案例、实验、任务、候选、选择）。需要可审计、可恢复且防篡改的存储设计。

## 决策

- 结构化状态存 SQLite 单库（SQLAlchemy + 显式 schema 版本迁移，事务内核验；启动恢复中断运行/任务/资产与未完成删除）。
- 二进制工件存不可变文件工件树（uploads/datasets/experiments/results/exports/render-assets/render-sources/comparisons/purge-quarantine/staging），路径由 settings 集中定义；工件写一律"临时写 -> 回读校验 -> 原子替换"，关键工件记录 SHA-256，读取前复核。
- 渲染资产内容寻址（`nc-<hash32>`），同身份逐字节相同；数据库登记与工件落盘用补偿事务，任一步失败清理残留并保留最初业务错误。
- 结构化字段一律 canonical JSON 文本；时间戳 UTC ISO-8601；公开输出走白名单 DTO，不暴露本机路径。
- 任务执行单进程单工作线程，数据库部分唯一索引兜底并发约束。

## 后果

- 正面：零部署、单文件可备份；哈希链使证据可审计；崩溃恢复语义明确；SQLite WAL 支撑演示期并发读。
- 代价：多进程/多机扩展受限（单 worker 设计）；工件树依赖文件系统原子性（Windows 上以 `os.replace` 保证）。
- 永久删除采用两阶段（隔离区 -> 提交）+ 操作回执表，误删可恢复窗口内可回滚。
