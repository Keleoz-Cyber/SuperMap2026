# 地矿属性模拟系统——Kimi 3 开发交接包

> 文档版本：0.1
> 审阅日期：2026-07-18
> 当前阶段：电阻率三维属性模拟 MVP
> 原则：原始资料只读，事实、选型、推断和待确认事项分开记录

代码项目根目录为当前仓库根目录；原始资料和标准化数据位于相邻的只读目录 `../超图杯资料`。

## 1. 项目目标

项目目标是建立可复现的地下属性数据管理、插值验证和三维表达流程，并逐步接入微震测量、煤层瓦斯与 DSI-like 算法。第一版不尝试一次完成三类数据融合，而是使用地下电阻率数据打通从标准数据到 SuperMap 三维成果的完整闭环。

MVP 的成功标准不是“生成一张三维效果图”，而是输入、参数、质量指标、失败记录和输出成果均能追溯并重复生成。

## 2. 已确认的产品决策

1. 第一版只实现电阻率三维属性模拟闭环；微震和瓦斯保留接口，不阻塞工程骨架。
2. 默认展示模型为 `Kriging 20m/40点`，正式对照模型为 `IDW 20m/25点`。
3. 不能宣称普通克里金全面优于 IDW：前者 MAE 更低，后者 RMSE、R² 和对数误差略优。
4. 五种候选模型共同存在 241 个无预测值，系统必须保留 NoData 掩膜，不能自动补值。
5. SuperMap 原生等值面当前尚未成功，不能把空结果数据集列为正式成果。

## 5. 已验证的电阻率成果

- 标准化数据：17,549 条；字段为 `X,Y,Z,RHO`。
- 训练集：15,827 条、264 根空间柱。
- 验证集：1,722 条、29 根空间柱，与训练集空间柱无交叉。
- 五种候选模型公共有效点：1,481；公共 NoData：241；覆盖率约 86.0%。
- `Kriging 20m/40点`：MAE 为 3.222594。
- `IDW 20m/25点`：RMSE 为 5.787635。
- SuperMap 正式候选体元：`RHO_KRIG_FINAL_20M_40`。
- 已验证显示：完整体元、典型水平切片和 `RHO >= 77` 高值过滤。

## 6. Kimi 3 的首个开发任务

第一批代码只建立以下基础能力：

1. 工程目录、配置模型、日志和错误模型；
2. 根据[数据契约](../03_数据规范/数据契约.md)读取并校验电阻率 CSV；
3. 登记输入文件哈希、记录数、坐标范围和数值范围；
4. 管理插值任务参数和 SuperMap 数据集名称；
5. 导入现有预测结果并计算或展示统一质量指标；
6. 建立成果清单，明确区分成功、失败和仅供预览的结果。

第一批代码不直接实现多源融合、DSI-like 或自动成矿预测。

## 7. 开发红线

- 不修改、移动、重命名或覆盖 `参考资料` 中的原始文件。
- 不用派生数据覆盖标准化源数据。
- 不把 `-9999` 当作真实电阻率参与统计、着色或插值。
- 不把 SuperMap 字段别名当作 SQL 真实字段名。
- 不把普通克里金或 IDW 描述为 DSI。
- 不把相对测线坐标描述为真实绝对地理坐标。
- 不在瓦斯 CRS 和孔口高程未确认时进行可信三维叠加。
- 不将失败任务、空数据集或未验证推断登记为正式成果。

## 8. 后续顺序

1. 完成电阻率 MVP 工程骨架和数据契约校验器；
2. 通过配置接入现有 SuperMap 体元与验证结果；
3. 验证补低值边界体元后的等值面提取；
4. 建立微震测线、测点和深度—速度采样三张标准表；
5. 确认煤层瓦斯 CRS、坐标轴、孔口高程和采样深度基准；
6. 最后再实现 DSI-like、多源融合和业务评价。
