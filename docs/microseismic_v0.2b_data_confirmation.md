# 微震 v0.2b 数据确认清单与证据登记

> 用途：帮助非专业使用者根据现有资料逐项确认 v0.2b 的数据条件。
> 本文档记录证据和决定，不替代原始数据、论文或资料提供者说明。

## 1. 怎么使用这份文档

1. 先阅读“已确认事实”，不要重复修改 v0.2a 已验证的数据事实。
2. 按四张确认卡查找资料，并把每条证据登记到统一证据表。
3. 只有证据足以形成可执行规则时，才把状态改为“已确认”。
4. 没有证据时保留“未确认”；存在矛盾时填写“存在冲突”。
5. 最后根据启动门槛更新下游阻断状态。

### 安全边界

- 原始 DAT、XLSX、PDF 和图片只读。
- 不根据示意图像素生成精确坐标或方位角。
- 不把 `WL/2(km)` 直接改名为深度或 Z。
- 不把无效值改成 0，也不覆盖原始记录。
- “审计通过”只说明已登记事实内部一致，不代表已经可以三维插值。

## 3. 当前阻断总览

“阻断”不是说项目失败，而是说现有证据还不足以安全执行对应步骤。继续保持阻断，可以防止错误坐标或错误清洗结果进入模型后变得难以追查。

| 下游工作 | 当前状态 | 主要原因 |
|---|---|---|
| 二维/三维几何重建 | 阻断 | 缺少原点、方向、坐标系和 Z 换算。 |
| 正式数据清洗 | 阻断 | 异常值比例和处理方法存在冲突。 |
| 微震空间插值 | 阻断 | 几何与 `WL/2(km)` 含义尚未确认。 |
| 证据整理与接口占位 | 可开展 | 不生成坐标、不清洗、不插值即可。 |

### 统一状态写法

- **未确认**：没有足够证据。
- **部分确认**：知道一部分，但仍缺公式、方向、基准或适用范围。
- **存在冲突**：不同来源不能同时成立。
- **已确认**：证据已经形成可执行、可复现的规则。
- **不适用**：有证据证明本项目不需要该项。

## 4. 确认卡 A：`WL/2(km)` 的含义和 Z 换算

### 大白话解释

源文件只告诉我们这一列叫 `WL/2(km)`。列名和单位不足以证明它就是深度；还需要知道它代表什么、正方向、换算公式以及 Z=0 在哪里。

可以把它理解成一个“标签还没解释清楚的尺子”。我们已经能读出尺子上的数，但还不知道它量的是什么，也不知道尺子的起点和正方向。因此现在不能把这些数直接放进地下三维空间。

### 为什么影响开发

- 如果把它错误地当成深度，所有微震点的竖直位置都会错误。
- 如果正负方向用反，地下异常会被翻到参考面另一侧。
- 如果忽略 km 到 m 的换算，模型尺寸会相差 1,000 倍。
- 如果没有 Z=0 的参考面，微震结果无法与电阻率、煤层或瓦斯数据对齐。

### 需要找到的答案

- [ ] `WL` 的完整名称和物理含义。
- [ ] 为什么数值除以 2。
- [ ] 数值增大表示更深、更高，还是其他方向。
- [ ] 从该字段到深度（m）的完整公式。
- [ ] 从深度到项目 Z 的符号规则和参考面。
- [ ] Vx 的正式物理含义和单位。

### 优先查找位置

1. 论文中介绍原始数据、速度反演或参数定义的章节。
2. DAT 文件生成软件的导出说明或字段字典。
3. 原始处理脚本、GOCAD 工程说明或采集单位提供的说明。
4. 论文作者或资料提供者的书面回复。

### 最低合格证据

原始数据字典、采集/处理说明、作者书面说明或可复现原始脚本，至少一种明确写出定义；如果要生成 Z，还必须同时给出公式、方向和参考面。

论文中仅出现字段名，或者数值看起来随某个方向变化，都不足以单独解除阻断。

- 解除阻断条件：定义、单位、方向、公式和参考面全部确认。

## 5. 确认卡 B：测线原点、方向和坐标系

### 大白话解释

点间距只能告诉我们测点沿一条线相隔多远，不能告诉计算机整条测线位于哪里、朝向哪里。

例如，知道 W1 到 W2 相距 150 m，只能说明两点之间的距离；如果不知道 W1 在哪里、W1→W2 朝哪个方向，就无法算出 W2 的 X/Y。

论文中的测线图可以说明 L2、L3 大致正交以及 L1 斜交等关系，但它是示意图。图片上的像素角度、长度和交点位置不能当成精确测量成果。

### 为什么影响开发

- 没有原点和方向，只能画出三条各自独立的一维线，不能正确相交。
- 没有 CRS 或完整本地坐标定义，微震结果不能与其他数据对齐。
- 不知道点序方向，可能把整条测线前后翻转。
- 没有 Z 基准，即使 X/Y 正确，也无法完成三维定位。

### 需要找到的答案

- [ ] L1 至少一个控制点的 X/Y 坐标及对应点号。
- [ ] L2 至少一个控制点的 X/Y 坐标及对应点号。
- [ ] L3 至少一个控制点的 X/Y 坐标及对应点号。
- [ ] L1、L2、L3 的点序前进方向。
- [ ] 方位角从什么方向起算、顺时针还是逆时针。
- [ ] 三条测线的方位角数值，或足以计算方位角的两个控制点。
- [ ] 坐标单位是 m、km，还是其他单位。
- [ ] 使用的 CRS/EPSG；如果是本地坐标，需给出原点、轴方向、单位和变换关系。
- [ ] 三条测线交点分别对应哪些点，是否确实共用同一空间位置。
- [ ] 高程或 Z 的参考基准。

### 怎么理解“方位角”

方位角用一个角度表示一条线在平面中朝哪个方向。工程中常见的约定是正北为 0°、顺时针增加，但本项目必须采用来源明确规定的约定，不能把常见习惯当成项目证据。

### 优先查找位置

1. 测量成果表、控制点坐标表或原始测线设计文件。
2. 采集报告中关于坐标系、测线布置和测点坐标的章节。
3. GOCAD、CAD、GIS 或其他工程文件中的坐标信息。
4. 资料提供者对原点、点序和方位角的书面确认。

### 最低合格证据

至少需要能唯一计算所有正式测点 X/Y 的数值条件，并明确坐标单位和坐标参考。若还要生成三维坐标，必须同时具有可信的 Z 规则。

## 6. 确认卡 C：异常值识别与填补

### 先区分三个概念

- **无效值**：无法作为有限数字使用，例如 `1.#QNAN0`。
- **异常值**：能够解析为数字，但根据明确规则判断不可信。
- **填补值**：为了形成连续数据，按批准方法计算出的新值。

这三者不能混为一谈。W8 的特殊 token 已经确定是无效数值，但“80 条异常值”必须有逐条清单或可复现规则才能确定具体是哪些记录。

### 为什么影响开发

- 不同异常检测规则会得到不同的删除或标记结果。
- 线性插值和 IDW 会产生不同的替代值，进而影响异常区位置。
- 如果邻域定义不清，“最近 5 点”可能指同一测点曲线、同一测线或三维空间中的不同点。
- 如果覆盖原值，之后无法判断结果来自观测还是填补。

### 当前存在的来源冲突

- 材料中出现“80 条异常值、3.59%”的表述。
- 以 2,005 条有限数值为分母，80/2,005 约为 3.99%，与 3.59% 不一致。
- 材料分别出现线性插值和邻近 5 点 IDW 两种处理方法。

### 需要找到的答案

- [ ] 80 条异常值的点号和源行号清单，或能复现相同结果的检测规则。
- [ ] 异常比例使用的分子、分母和数据版本。
- [ ] 正式采用线性插值、邻近 5 点 IDW，还是其他方法。
- [ ] 邻域是在同一测点曲线、同一测线，还是空间坐标中定义。
- [ ] 邻近点数量、距离权重指数和搜索边界。
- [ ] 首尾位置或邻点不足时如何处理。
- [ ] 是否保留原始值、异常标记、填补值和处理原因。
- [ ] 清洗规则版本和批准人。

### 最低合格证据

必须有逐记录清单或可执行规则，并明确分母、方法参数、邻域、边界处理和审计字段。仅知道“删除了 80 条”不足以复现正式清洗结果。

### 当前登记

- 状态：**存在冲突**
- 候选方法：线性插值；邻近 5 点 IDW。
- 暂定处理：不生成正式清洗表，不修改任何原始 token 或数值。
- 解除阻断条件：异常对象、比例口径、正式方法、邻域和边界处理全部确认。

| 来源/口径 | L1 | L2 | L3 | 总数 |

### 为什么影响开发

- 如果输入集合不确定，后续清洗和模型无法稳定复现。
- 为了迎合论文而移动 L1/L2 记录，会破坏原始文件与测点的对应关系。
